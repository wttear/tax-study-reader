# 세무사 제2차 기출 세부문항 학습 리더 설계

## 배경

현재 공개 사이트는 429개 기출 답안 작성 단위를 목록으로 제공하지만, 각 행에는 자체 작성 문제 요약과 Q-Net 외부 파일 링크만 보인다. 데이터에는 학습용 답안 요소가 일부 존재해도 화면에서 문제 원문, 완성형 답안, 초보자용 해설을 한 문항의 연속된 학습 흐름으로 읽을 수 없다. 사용자가 원하는 중심 경험은 쟁점 목록 탐색이 아니라 기출 세부문항 하나를 문제부터 관련 쟁점까지 끊김 없이 학습하는 것이다.

## 목표

- 2011년부터 2026년까지의 세무사 제2차 세법학 기출을 429개 세부문항 단위로 제공한다.
- 각 문항에서 문제 원문, 쉬운 문제 해석, 핵심 정답, 완성형 학습용 모범답안, 초보자 해설, 관련 쟁점을 한 화면에 제공한다.
- 모바일에서 위에서 아래로 읽는 것만으로 문제 이해부터 심화학습까지 도달하게 한다.
- 완료·숙달·진도 상태를 요구하지 않고 모든 문항을 자유롭게 열람하게 한다.
- 기존 70개 쟁점 학습 허브를 문항별 심화학습 목적지로 재사용한다.

## 비목표

- 사용자의 답안을 채점하거나 점수를 저장하지 않는다.
- 완료 상태, 잠금, 강제 순서, 계정 기능을 추가하지 않는다.
- Q-Net이 공식 모범답안을 공개하지 않은 서술형 문항에 공식답안이라는 표현을 사용하지 않는다.
- 최신판례 메뉴를 기출 학습 화면에 합치지 않는다. 필요한 판례만 문항과 관련 쟁점에 연결한다.

## 결정된 사용자 흐름

기출 목록에서 연도·과목·문제번호·법률·쟁점으로 문항을 찾는다. 목록 행을 누르면 세부문항 하나의 독립 상세 페이지로 이동한다. 상세 페이지는 다음 순서로 모든 내용을 기본 노출한다.

1. **기출문제 원문**
   - 세부 문항 원문
   - 풀이에 필요한 큰 문제의 공통 사실관계, 표, 조건
   - 연도, 회차, 과목, 문제번호, 소문항 번호, 확인 가능한 배점
   - Q-Net 출처, 기준일, 공공누리 제1유형 출처표시
2. **초보자용 문제 읽기**
   - 이 문제가 요구하는 결과물
   - 찾아야 할 핵심 사실
   - 먼저 알아야 할 개념
   - 혼동하기 쉬운 함정
3. **한눈에 보는 정답**
   - 결론과 답안 목차를 3~5개 항목으로 요약
4. **완성형 학습용 모범답안**
   - 쟁점, 시험 당시 법령·판례, 사실 포섭, 결론 순서의 서술형 답안
   - 계산형 문항의 입력값, 산식, 중간 계산, 최종 결론
   - 회계처리와 세무조정을 요구하는 문항의 분개·조정 방향
   - `학습용 모범답안이며 공식답안이 아님` 표시
5. **초보자용 답안 해설**
   - 답안 각 문단이 필요한 이유
   - 어려운 법률·회계 용어의 일상어 풀이
   - 흔한 오답과 누락
6. **관련 쟁점 연결**
   - 직접 쟁점과 확장 쟁점의 구분
   - 각 연결이 필요한 이유
   - 기존 쟁점 학습 리더로 가는 직접 링크
7. **문항 이동**
   - 화면 하단에 이전 문항, 기출 목록, 다음 문항을 항상 제공

상세 페이지는 답안과 해설을 탭이나 아코디언 안에 숨기지 않는다. 사용자는 화면 내 목차 링크로 원하는 구역에 바로 이동할 수 있지만 기본 학습 순서는 원문부터 관련 쟁점까지의 세로 흐름이다.

## 정보구조와 URL

- 기출 입구: `/exams/`
- 전체 기출 검색·필터: `/exams/archive/`
- 세부문항 상세: `/exams/questions/<exam-question-id>/`
- 관련 쟁점 리더: 기존 `/lesson-reader/<topic>.html`
- 최신판례: 기존 `/precedents/`

기출 목록과 쟁점 허브의 문항 링크는 같은 세부문항 상세 URL을 사용한다. 이전·다음은 2011년부터 2026년까지의 정규 문항 순서에 따라 결정한다. URL은 문항 ID로 고정하여 제목이나 분류가 바뀌어도 깨지지 않게 한다.

## 문항 데이터 계약

각 429개 세부문항은 다음 필드를 필수로 가진다.

- `exam_question_id`: 기존 고정 문항 ID
- `identity`: 연도, 회차, 과목, 대문항, 소문항, 배점
- `official_source`: Q-Net 게시물 URL, 첨부파일 URL, 출처 기준일, 공공누리 유형
- `original_prompt`: 세부문항 원문
- `shared_context`: 풀이에 필요한 공통 사실관계, 표, 조건의 순서화된 블록
- `beginner_reading`: 요구사항, 핵심 사실, 선수 개념, 함정
- `answer_at_a_glance`: 3~5개의 결론·목차 항목
- `model_answer`: 역할이 표시된 쟁점·규범·포섭·결론 문단과 계산·회계·세무조정 블록
- `paragraph_explanations`: 모범답안 문단과 일대일로 연결된 초보자 해설
- `law_at_exam`: 시험 당시 시행 법령과 기준일
- `current_law_difference`: 현재 법령과 달라진 점
- `precedent_connections`: 사건번호, 법리, 문항과의 관계
- `related_issues`: 직접·확장 관계, 연결 이유, 학습 리더 URL
- `common_mistakes`: 자주 누락하는 내용과 잘못된 접근
- `variant_question`: 사실관계를 바꾼 연습 문제
- `answer_status`: 공식답안 유무와 학습용 답안 고지

문제 원문과 자체 작성 설명은 별도 필드로 보관하고 시각적으로도 구분한다. 공통 사실관계는 여러 세부문항이 참조할 수 있지만, 상세 페이지 생성 시 해당 문항을 푸는 데 필요한 내용이 페이지 안에 함께 렌더링되어야 한다.

## 출처와 권리 표시

Q-Net 세무사 기출 게시물에 표시된 공공누리 제1유형을 연도별 게시물 단위로 확인한다. 문제 원문을 공개하는 상세 페이지에는 한국산업인력공단 Q-Net을 출처로 표시하고 해당 공식 게시물로 연결한다. 원문은 의미를 바꾸어 편집하지 않으며 줄바꿈, 번호, 표의 구조를 가능한 한 보존한다. 초보자용 재설명과 모범답안은 사이트 자체 작성 콘텐츠임을 별도로 표시한다.

서술형 기출에 공식 모범답안이 확인되지 않으면 `학습용 모범답안이며 공식답안이 아님`을 답안 제목과 메타데이터에 함께 표시한다. 공식답안이 확인되는 경우에만 출처와 함께 공식답안 상태를 사용한다.

## 생성 구조

1. 연도별 Q-Net 게시물과 첨부파일을 출처 목록으로 관리한다.
2. HWP, PDF, ZIP에서 원문 구조를 추출하고 세부문항 ID에 연결한다.
3. 큰 문제의 공통 사실관계와 표를 구조화된 블록으로 보존한다.
4. 기존 문항 메타데이터와 학습용 답안 요소를 새 데이터 계약으로 확장한다.
5. 검증기가 429개 문항의 필수 필드, 링크, 출처, 관계를 검사한다.
6. 정적 생성기가 목록·쟁점 허브의 링크와 429개 상세 페이지를 만든다.
7. GitHub Pages 빌드 전에 콘텐츠·보안·모바일 회귀 테스트를 수행한다.

문항 상세 렌더러와 문항 데이터 검증기는 분리한다. 검증기는 콘텐츠의 완전성과 관계를 책임지고, 렌더러는 검증된 공개 모델만 HTML로 변환한다. 원본 파일 파서의 출력은 바로 공개하지 않고 정규화·검수된 문항 데이터만 생성기에 전달한다.

## 실패 처리

- 원문, 공통 사실관계, 모범답안, 초보자 해설 중 하나라도 없으면 해당 문항을 축약 공개하지 않고 전체 빌드를 실패시킨다.
- 공식 출처 URL 또는 공공누리 표시가 확인되지 않으면 원문 전문 공개 상태로 전환하지 않는다.
- 관련 쟁점에 연결 이유나 유효한 학습 리더 URL이 없으면 빌드를 실패시킨다.
- 모범답안 문단과 초보자 해설의 연결 수가 맞지 않으면 빌드를 실패시킨다.
- 시험 당시 법령 기준일이 불명확하면 임의 날짜를 만들지 않고 확인 상태와 적용 근거를 명시한다.
- 표나 계산 조건을 텍스트로 안전하게 보존할 수 없으면 이미지 대체텍스트와 구조화 표를 함께 준비할 때까지 문항을 완료로 처리하지 않는다.

## 모바일·접근성

- 본문은 한 열로 렌더링하고 가로 스크롤 없이 읽을 수 있게 한다.
- 모든 링크와 버튼의 최소 터치 영역은 44px로 한다.
- 페이지 안 목차와 구역 제목을 사용해 스크린리더와 키보드 탐색을 지원한다.
- 하단 문항 이동 영역은 안전영역을 고려하고 본문을 가리지 않는다.
- 문제 원문, 자체 작성 설명, 학습용 모범답안의 출처·성격을 색상뿐 아니라 텍스트 라벨로 구분한다.
- 자바스크립트가 꺼져도 본문 전체와 이전·목록·다음 링크가 보인다.

## 검증 전략

### 데이터 완전성

- 정확히 429개의 고유 문항 ID와 429개의 상세 페이지가 존재한다.
- 모든 문항에 원문, 답안, 초보자 해설, 관련 쟁점 연결이 있다.
- 큰 문제의 공통 사실관계를 필요로 하는 세부문항에는 해당 문맥이 포함된다.
- 각 연도 Q-Net 출처와 공공누리 표시가 검증된 메타데이터로 존재한다.

### 법률·학습 정확성

- 시험 당시 법령과 현재 법령을 혼용하지 않는다.
- 법령 조문, 판례 사건번호, 계산 산식, 회계처리, 세무조정 연결을 검증한다.
- 모범답안의 각 문단이 초보자 해설과 일대일로 연결된다.
- 초보자용 문제 해석은 원문을 반복하는 데 그치지 않고 요구사항·핵심 사실·선수 개념·함정을 설명한다.
- 관련 쟁점은 관계 유형과 연결 이유를 포함한다.

### 페이지와 모바일 회귀

- 목록, 쟁점 허브, 상세 페이지, 이전·다음 링크가 서로 일관되게 연결된다.
- 직접 URL과 새로고침으로 같은 문항을 연다.
- 모바일 폭에서 본문, 표, 하단 탐색이 겹치거나 잘리지 않는다.
- 완료 상태나 잠금 없이 모든 문항을 연다.
- 자바스크립트 비활성 상태에서도 핵심 학습 콘텐츠를 읽는다.

### 안전성

- 원문과 자체 작성 필드는 HTML로 안전하게 이스케이프한다.
- 외부 링크는 Q-Net과 승인된 법령·판례 출처만 허용한다.
- 공개 HTML에 로컬 경로, 비공개 파일 위치, 개인정보를 포함하지 않는다.
- JSON 표시 데이터와 템플릿 토큰의 주입을 차단한다.

## 기존 구조의 변경 범위

- `/exams/archive/`는 다운로드 중심 대장이 아니라 상세 학습 페이지로 들어가는 검색 목록이 된다.
- `/exams/`의 70개 쟁점 허브는 유지하되 각 기출 근거가 세부문항 상세 페이지를 가리키게 한다.
- 기존 429개 문항의 학습용 답안 요소를 재사용하되, 문제 원문·쉬운 문제 읽기·문단별 해설·연결 이유를 새 계약에 맞게 보강한다.
- 최신판례 메뉴와 기존 일일학습 리더는 독립 구조를 유지한다.

## 완료 기준

다음 조건을 모두 만족할 때 기능이 완료된다.

1. 모바일 공개 사이트에서 429개 세부문항을 각각 독립 URL로 연다.
2. 모든 상세 페이지가 원문부터 관련 쟁점까지 승인된 B안 순서로 표시된다.
3. 원문 출처와 학습용 모범답안의 성격이 명확히 구분된다.
4. 관련 쟁점 링크가 연결 이유와 함께 실제 학습 리더로 이동한다.
5. 전체 데이터·법률·페이지·보안 테스트가 통과한다.
6. GitHub Pages 배포 후 대표 문항과 경계 연도의 상세 URL을 모바일 크기로 검증한다.
