# 법령 중심 세법 학습 화면 설계

## 상태

- 설계 승인일: 2026-09-01 (Asia/Seoul)
- 승인된 화면안: A안 — 법령 원문부터 판례까지 한 페이지 연속 읽기
- 1차 법률 범위: 국세기본법, 국세징수법, 법인세법, 소득세법, 부가가치세법
- 제외 범위: 상속세 및 증여세법, 개별소비세법, 지방세법, 조세특례제한법

## 목표

사용자가 법률을 먼저 선택하고, 선택한 조문에서 법률 원문·연결 시행령 원문·초보자 해설·과세쟁점과 세무조사 적용·중요 판례를 한 흐름으로 읽을 수 있는 모바일 우선 정적 학습 화면을 추가한다. 기존 대시보드·기출·최신판례 화면은 유지하고, 조문과 기존 학습 자료를 안정적인 ID로 연결한다.

## 사용자 흐름

```text
법령 학습
  → 5개 법률 목록
  → 선택한 법률의 전체 조문 목록
  → 조문 상세
       → 현행 법률 원문
       → 연결 시행령 원문
       → 시험 당시 법령·연혁 메모(해당 시)
       → 초보자용 해설
       → 과세쟁점·세무조사·회계·세무조정
       → 관련 기출
       → 중요 판례 여러 건
```

조문 목록은 모든 조문을 노출한다. 콘텐츠는 기존 116개 핵심 쟁점이 연결된 조문부터 완성하고, 나머지는 원문·공식 출처·해설 상태를 표시한 뒤 순차 보강한다. 모든 페이지는 로그인·완료 버튼·잠금 없이 자유열람한다.

## 정보 구조와 경로

```text
/laws/
  5개 법률 목록
/laws/{law_code}/
  선택한 법률의 전체 조문 목록
/laws/{law_code}/{article_id}/
  법률 원문부터 판례까지의 조문 상세
```

기존 경로는 변경하지 않는다.

```text
/dashboard/
/exams/
/exams/archive/
/precedents/
```

조문 상세의 상단에는 `법률 원문 · 시행령 · 쉬운 해설 · 과세쟁점 · 판례` 앵커 목차를 둔다. 탭으로 본문을 교체하지 않고 같은 문서의 위치로 이동하여 A안의 연속 읽기 흐름을 보존한다. 하단에는 이전 조문·조문 목록·다음 조문 링크를 둔다.

## 법률 목록과 조문 목록

### 법률 목록

`/laws/`에는 다음 다섯 법률만 표시한다.

1. 국세기본법
2. 국세징수법
3. 법인세법
4. 소득세법
5. 부가가치세법

각 카드에는 법률명, 전체 조문 수, 학습 콘텐츠가 있는 핵심 조문 수를 표시한다. 진도율이나 완료 상태는 표시하지 않는다.

### 조문 목록

`/laws/{law_code}/`에는 해당 법률의 모든 조문을 번호 순으로 표시한다. 조문 번호·제목·키워드 검색과 다음 필터를 제공한다.

- 핵심 개념
- 신고·납부
- 세무조사·증빙
- 불복·구제
- 회계처리·세무조정

각 행에는 핵심 콘텐츠 상태, 연결 과세쟁점 수, 관련 판례 수를 표시한다. 조문 상세가 아직 없는 행도 공식 원문 링크와 `학습 콘텐츠 준비 중` 상태로 열어 둔다.

## 조문 상세 화면 — A안

### 01. 법률 원문

- 법률명, 조문 번호, 조문 제목
- 현행 법률 원문을 기본 표시
- 항·호·목의 번호와 들여쓰기를 보존
- 국가법령정보센터 공식 링크
- 시행일, 공포 정보, 출처 확인일, 콘텐츠 해시

### 02. 연결 시행령 원문

- 법률 조문이 위임하거나 직접 참조하는 시행령 조문만 표시
- 법률의 항·호와 시행령의 요건을 대응 번호로 표시
- 각 시행령 조문에 공식 원문 링크와 시행일 표시
- 직접 연결되는 시행령이 없으면 임의 내용을 만들지 않고 부재 안내를 표시

### 03. 시험 당시 법령·연혁

기출 또는 특정 적용시점이 있는 조문에만 표시한다. 시험일·거래일을 공식 자료로 확정할 수 없으면 날짜를 추정하지 않고 `정확한 기준일 확인 불가`로 표시한다. 현행 조문과 시험 당시 조문은 서로 다른 버전 ID로 보존한다.

### 04. 초보자용 해설

원문 바로 아래에 다음 순서로 둔다.

1. 한 줄 요약 — 이 조문이 정하는 것
2. 문장별 쉬운 말 — 항·호 단위의 용어 풀이
3. 간단한 사례 — 비식별 사실관계와 요건 대입
4. 시행령 연결 설명 — 법률 원칙과 시행령 구체화의 관계
5. 체크포인트 — 적용 대상, 시점, 필요 자료, 누락 위험

원문과 해설은 색상만으로 구분하지 않고 `법률 원문`, `시행령 원문`, `쉬운 말`, `사례`, `체크포인트`라는 텍스트 라벨을 함께 사용한다.

### 05. 과세쟁점·세무조사·회계

한 조문에 여러 쟁점이 있으면 쟁점 카드를 여러 개 만든다. 각 쟁점 카드는 다음을 포함한다.

- 쟁점 질문
- 법률 요건과 적용 순서
- 대표 사실관계
- 조사에서 확인할 장부·계좌·세금계산서·계약서·신고서
- 자료 간 대사 방법과 입증책임
- 신고·경정·불복에서의 적용
- 필요한 경우 회계 분개, 익금·손금, 유보·상여 등 세무조정
- 관련 세무사 2차 기출과 출제 의도
- 난이도와 기출 연결 빈도

기존 116개 핵심 쟁점과 70개 기출 쟁점은 쟁점 ID를 공유한다. 설명을 여러 페이지에 복사하지 않고 조문에서 동일 쟁점 모델을 참조한다.

### 06. 관련 기출

조문과 직접 연결된 기출을 먼저 표시하고, 관련 연결은 별도 배지로 구분한다. 기출 원문·학습용 모범답안·문단 해설은 기존 `/exams/` 상세 페이지로 이동시킨다. 기출 자료의 공식 이용조건과 `공식 답안이 아님` 안내를 유지한다.

### 07. 중요 판례

과세쟁점 뒤에 판례 카드를 표시한다. 판례가 여러 건이면 모두 연결한다. 각 카드에는 다음을 표시한다.

- 법원·사건번호·선고일
- 판결이 다룬 조문
- 핵심 사실관계
- 판결요지
- 판단 이유
- 현재 법령에 미치는 영향
- 해당 조문과 연결되는 이유
- 직접 관련·보조 관련 구분
- 국가법령정보센터 공식 판례 링크와 확인일

공식 판례 원문을 확인하지 못한 사건은 사건번호나 결론을 만들어 넣지 않고 `공식 원문 확인 필요`로 분리한다. 최신판례 메뉴는 유지하며, 조문 페이지에는 해당 조문과 관련된 판례만 선별한다.

## 데이터 모델

법률별 파일을 분리하여 변경 범위를 작게 유지한다.

```text
data/laws/
├─ catalog.json
├─ ntba.json
├─ ncta.json
├─ cta.json
├─ ita.json
└─ vat.json
```

`catalog.json`은 법률 코드·명칭·표시 순서·전체 조문 수를 보관한다. 법률 파일의 최소 모델은 다음과 같다.

```json
{
  "law_code": "NTBA",
  "law_name": "국세기본법",
  "articles": [
    {
      "article_id": "NTBA-16",
      "article_number": "제16조",
      "title": "근거과세",
      "versions": [
        {
          "version_id": "NTBA-16-CURRENT-2026-04-24",
          "status": "current",
          "effective_date": "2026-04-24",
          "text": "장부와 증빙에 의하여 과세표준을 조사·결정한다.",
          "official_url": "https://www.law.go.kr/법령/국세기본법/(20260424,21216,20251223)",
          "source_sha256": "0123456789abcdef0123456789abcdef0123456789abcdef0123456789abcdef",
          "checked_at": "2026-09-01"
        }
      ],
      "decree_article_ids": ["NTBA-D-63"],
      "issue_ids": ["NTBA-BASIS-001"],
      "precedent_ids": ["SC-2006DU8068"],
      "exam_question_ids": ["EXAM-2014-P1-Q1-S1"],
      "content_status": "core"
    }
  ]
}
```

실제 구현에서는 해설·쟁점·판례 객체를 별도 공유 레지스트리로 둘 수 있지만, 모든 참조는 검증 가능한 안정 ID로만 연결한다. 법령 버전에는 공식 URL·시행일·확인일·SHA-256을 필수로 둔다.

## 구성요소 책임

- `laws.py`: 5개 법률, 조문·버전·시행령·참조 ID·공식 URL 검증
- `law_reader.py`: 조문 상세 모델 생성과 A안 HTML 렌더링
- `templates/law-index.html`: 법률 카드와 조문 목록 템플릿
- `templates/law-reader.html`: 원문부터 판례까지의 연속 읽기 템플릿
- `pages.py`: `/laws/`와 조문 상세 정적 파일 생성 및 원자적 게시
- 기존 `exam_*`, `precedents.py`: 기출·판례 모델과 공식 출처 재사용

콘텐츠 본문은 정적 HTML에 포함한다. 검색·필터·앵커 이동은 점진적 향상으로 제공하며, 자바스크립트가 꺼져도 원문과 해설을 읽을 수 있어야 한다.

## 데이터 흐름과 갱신

```text
공식 법령·판례 자료
  → 버전·해시 검증
  → 법률별 모델 로드
  → 조문·시행령·쟁점·판례 참조 검증
  → 법률 목록·조문 목록·상세 HTML 생성
  → 임시 디렉터리 검사
  → 공개 저장소 docs로 원자 교체
```

법령 개정 시에는 원문과 시행일을 먼저 갱신하고, 영향을 받는 해설·쟁점·판례를 검토대기로 표시한다. 공식 확인 전에는 기존 검증본을 자동으로 덮어쓰지 않는다. 시험 당시 버전은 현행 버전과 분리하여 보존한다.

## 오류 처리와 안전성

- 5개 법률 이외의 법률은 목록과 상세 생성 대상에서 제외한다.
- 없는 조문·시행령·쟁점·판례 ID는 생성 실패로 처리한다.
- 국가법령정보센터·공식 판례 도메인이 아닌 URL은 거부한다.
- 시험일·거래일을 추정하지 않고 확인 불가 상태를 표시한다.
- 원문 HTML을 그대로 실행하지 않고 텍스트를 이스케이프한다.
- 생성 중 오류가 나면 기존 정상 공개 사이트와 원본 데이터를 보존한다.
- 임시 파일·스테이징 디렉터리는 고유 경로로 만들고 실패 시 정리한다.
- 같은 입력·템플릿·데이터는 바이트 단위로 동일한 HTML을 생성한다.
- 원문과 학습용 해설을 시각·텍스트 라벨로 구분한다.

## 반응형·접근성 기준

- 모바일 한 열을 기본으로 한다.
- 본문은 최소 17px, 행간 1.7, 넓은 화면 줄 길이 68ch 이하
- 법령 항·호 번호와 긴 문장을 자동 줄바꿈
- 표는 모바일에서 행별 카드로 전환
- 상단 앵커 목차는 가로 넘침 없이 줄바꿈·스크롤 가능
- `h1`부터 의미 있는 제목 순서와 landmark 사용
- 키보드 포커스·skip link·44px 이상의 조작 영역 제공
- 색상 외에 텍스트 라벨과 아이콘으로 상태 구분
- 인쇄 시 조작 요소를 숨기고 원문 출처·기준일·해설을 보존

## 단계적 공개

1. 5개 법률 카드와 전체 조문 목록 공개
2. 기존 핵심 116개 쟁점 조문에 완성형 상세 페이지 공개
3. 나머지 조문에 원문·공식 출처·연결 시행령을 보강
4. 해설·과세쟁점·회계·세무조정·판례를 검증 순서대로 추가

콘텐츠가 아직 없는 조문도 숨기지 않는다. 상세 페이지에는 준비 상태와 공식 원문 링크를 표시한다.

## 검증 계획

구현 전에 다음 계약 테스트를 추가한다.

1. 법률 목록이 정확히 5개인지 검증
2. 법률별 조문 ID와 버전 ID의 중복·형식 검증
3. 시행령·쟁점·판례·기출 참조의 존재성 검증
4. 공식 URL 도메인·HTTPS·해시·확인일 검증
5. 상세 HTML 순서가 법률 → 시행령 → 연혁 → 해설 → 쟁점 → 기출 → 판례인지 검증
6. 원문·해설·판례가 비어 있거나 임의 placeholder인 경우 거부
7. 원문 HTML·위험 URL·경로 순회·제어문자 차단
8. 같은 입력의 재생성이 바이트 동일한지 검증
9. 누락·렌더링·게시 실패 시 기존 출력이 보존되는지 검증
10. 모바일 viewport·긴 조문 줄바꿈·앵커·키보드 접근성 계약 검증
11. 기존 대시보드·기출·판례·진도 원장 회귀 테스트

## 인수 기준

- 휴대폰에서 `/laws/`를 열어 5개 법률 중 하나를 선택할 수 있다.
- 선택한 법률의 모든 조문을 번호·제목·검색·필터로 찾을 수 있다.
- 핵심 조문은 한 페이지에서 법률 원문·시행령 원문·초보자 해설·과세쟁점·세무조사 적용·회계·세무조정·기출·중요 판례를 순서대로 읽을 수 있다.
- 판례가 여러 건이면 모두 공식 링크와 연결 이유가 보인다.
- 현행법과 시험 당시 법령이 섞이지 않고 기준일·연혁이 표시된다.
- 완료 버튼·잠금·로그인 없이 자유열람할 수 있다.
- 자바스크립트 없이도 원문과 핵심 해설을 읽을 수 있다.
- 공식 출처가 확인되지 않은 법령·판례를 사실처럼 노출하지 않는다.
- 기존 `/dashboard/`, `/exams/`, `/precedents/` 화면과 데이터가 손상되지 않는다.
