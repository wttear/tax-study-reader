02

초보자용 문제 읽기

무엇을 답해야 하나요?

면세사업용 감가상각자산 전부를 과세사업에 사용할 때 경과 과세기간을 반영한 공제액을 계산한다.

핵심 사실

  • 부가가치세는 재화나 용역이 생산되거나 유통되는 모든 거래단계에서 생성되는 부가가치를 과세대상으로 하는 간접세를 말한다.
  • 건물 전부를 면세사업에서 과세사업으로 전환할 때 최초 불공제 매입세액에서 경과 과세기간마다 5%씩 체감한 잔존액을 공제한다.

먼저 알 개념

  • 시험 당시 적용할 직접 법령은 부가가치세법 시행령 제85조, 부가가치세법 제40조이다.
  • 건물 전부를 면세사업에서 과세사업으로 전환할 때 최초 불공제 매입세액에서 경과 과세기간마다 5%씩 체감한 잔존액을 공제한다.
  • 산식: 건물 전부 전환 공제액=최초 불공제 매입세액×, 0원 미만은 0원.
  • 사실포섭,소결: 산식은 건물 공제액=최초 불공제 매입세액×이다.
  • 증빙,세무조사 활용: 원매입세액, 건물 취득,전환 과세기간과 감가상각자산 종류별 체감률을 검산한다.

헷갈리기 쉬운 점

  • 먼저 표시할 사실: 부가가치세는 재화나 용역이 생산되거나 유통되는 모든 거래단계에서 생성되는 부가가치를 과세대상으로 하는 간접세를 말한다. 이 사실이 적용 범위를 가른다.
  • 따로 확인할 사실: 건물 전부를 면세사업에서 과세사업으로 전환할 때 최초 불공제 매입세액에서 경과 과세기간마다 5%씩 체감한 잔존액을 공제한다. 앞 사실과 섞지 않고 별도로 판단한다.
  • 현행 대조: 전부 과세전환 시 공제 매입세액 계산 — 시험일 기준: ; 부가가치세법 시행령 제85조(2019년 시행본). 2026-08-29 현재 확인 항목: 건물 체감률,경과기간 계산과 현행 과세전환 조정률. 이 기록은 시험일 시행본을 고정하며, 2026 신고 결론은 해당 최신 시행본 대조 후 정한다.

  3. 사실포섭,소결: 산식은 건물 공제액=최초 불공제 매입세액×이다.
  4. 증빙,세무조사 활용: 원매입세액, 건물 취득,전환 과세기간과 감가상각자산 종류별 체감률을 검산한다.
04

완성형 학습용 모범답안

학습용 모범답안이며 공식답안이 아님Q-Net 공식 채점기준이 아님
문단 1 · 쟁점

쟁점은 전부 과세전환 시 공제 매입세액 계산: 면세사업용 감가상각자산 전부를 과세사업에 사용할 때 경과 과세기간을 반영한 공제액을 계산한다.

문단 2 · 법령·법리

법리·법정요건: 건물 전부를 면세사업에서 과세사업으로 전환할 때 최초 불공제 매입세액에서 경과 과세기간마다 5%씩 체감한 잔존액을 공제한다. 기타 감가상각자산은 당시 법정 체감률을 적용한다. 시험연도 적용근거는 부가가치세법 시행령 제85조(2019년 시행본)이다.

문단 3 · 계산

건물 전부 전환 공제액=최초 불공제 매입세액×(1-5%×경과 과세기간 수), 0원 미만은 0원. 소결: 전부 전환이므로 추가 면적비율은 곱하지 않는다.

문단 4 · 사실 포섭

증빙·세무조사 활용: 원매입세액, 건물 취득·전환 과세기간과 감가상각자산 종류별 체감률을 검산한다.

문단 5 · 결론

사실포섭·소결: 산식은 건물 공제액=최초 불공제 매입세액×(1-5%×경과 과세기간 수)이다. 괄호가 0 이하이면 공제액은 0원이고, 전부 전환이므로 별도 과세사용비율을 곱하지 않는다. 경과 과세기간 수를 정확히 세어 잔존매입세액 전액을 전환 과세기간에 공제한다.

05

초보자용 답안 해설

문단 1 · 쟁점

왜 필요한가요?

신고 전 전부 과세전환 시 공제 매입세액 계산의 계산축을 계산축으로 세운다. 수치는 “부가가치세의 계산축”에서 읽는다. 부가령 제85조를 대입해 정리한다.

쉬운 말로

소득 구분 전부 과세전환 시 공제 매입세액 계산의 원칙과 예외를 계산축으로 가른다. “건물의 검산표” 자료를 검산표로 살핀다. 부가령 제85조로 효과를 설명한다.

문단 2 · 법령·법리

왜 필요한가요?

자료 대조 전부 과세전환 시 공제 매입세액 계산과 “건물의 예외표”의 연결을 예외표로 선별한다. 부가가치세법 제40조와 순서표를 읽는다. 조사자료는 조문표로 대조한다.

쉬운 말로

두 번째 부가가치세법 제40조가 정한 예외표를 읽는다. 전부 과세전환 시 공제 매입세액 계산에 “부가가치세의 순서표” 자료를 순서표로 대입한다. 결과는 조문표로 적는다.

문단 3 · 계산

왜 필요한가요?

수치 검산 전부 과세전환 시 공제 매입세액 계산의 판단 질문을 연결고리로 만든다. “부가가치세의 연결고리” 자료를 대사표로 확인한다. 부가령 제85조 근거는 답안에 대사표로 남긴다.

쉬운 말로

메모할 때 전부 과세전환 시 공제 매입세액 계산을 연결고리로 복습한다. 법령은 부가령 제85조로 확인하고, “건물의 대사표”에서 핵심을 대사표로 다시 본다.

문단 4 · 사실 포섭

왜 필요한가요?

초보자 전부 과세전환 시 공제 매입세액 계산을 예외표로 검산한다. 부가가치세법 제40조에서 금액표를 읽는다. 세무조사에서는 “건물의 예외표” 자료를 주체표로 확인한다.

쉬운 말로

계산 전 “부가가치세의 금액표”라는 사실을 예외표로 표시한다. 전부 과세전환 시 공제 매입세액 계산이 부가가치세법 제40조의 범위에서 판단한다. 주체표에서 증빙은 금액표로 맞춘다.

문단 5 · 결론

왜 필요한가요?

기초부터 부가령 제85조가 정한 적용축을 먼저 본다. 전부 과세전환 시 공제 매입세액 계산에 “부가가치세의 적용축” 자료를 귀속칸으로 옮긴다. 확인축에서 결론은 부가령 제85조를 근거로 분해한다.

쉬운 말로

답안에서는 세무조사에서는 “건물의 귀속칸” 증빙을 적용축으로 찾는다. 전부 과세전환 시 공제 매입세액 계산이 부가령 제85조 선에서 정한다. 확인축에서 결론은 귀속칸으로 기록한다.

관련 쟁점 연결

direct

과세·면세 공통매입세액 안분과 재계산

부가가치세법

부가가치세법 제40조의 기준을 자료표로 적는다. 전부 과세전환 시 공제 매입세액 계산의 판단은 귀속선에서 본다. 세무조사에서는 “부가가치세의 자료표” 자료를 거래표로 대조한다.

related

승용차·기업업무추진·토지·면세 관련 매입세액

부가가치세법

세무조사에서는 “건물의 적용표” 증빙을 적용표로 찾는다. 전부 과세전환 시 공제 매입세액 계산의 효과는 부가령 제85조와 연결한다.

자주 하는 실수

  • 답안에서 빠지기 쉬운 내용은 [전부 과세전환 시 공제 매입세액 계산에서 부가가치세법 시행령 제85조(2019년 시행본)의 적용시점과 법정요건을 쓰지 않는 것]이다. 관련 법령인 부가가치세법 시행령 제85조의 요건과 전부 과세전환 시 공제 매입세액 계산의 효과까지 적어야 결론이 완성된다.
  • 답안에서 빠지기 쉬운 내용은 [전부 과세전환 시 공제 매입세액 계산의 소결에 이르는 핵심 사실과 반대사실을 증빙에 연결]이다. 관련 법령인 부가가치세법 시행령 제85조의 요건과 전부 과세전환 시 공제 매입세액 계산의 효과까지 적어야 결론이 완성된다.
