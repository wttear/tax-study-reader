초보자용 문제 읽기

무엇을 답해야 하나요?

동업자 지분 이전이 지체되어 법원 수용보상금에서 받은 3억 원의 출자금,이익 반환 성격을 구분한다.

핵심 사실

  • 甲은 2억 원을 출자하고 乙과 부동산매매업을 직접 공동 수행하며 손익을 나눠 가졌다.
  • 2017년 4월 동업을 끝내며 乙 소유 과수원을 甲의 출자금 2억 원 반환에 갈음하여 이전하기로 했다.
  • 소유권이전이 지연되는 사이 과수원이 수용되어 甲은 판결로 수용보상금 3억 원을 받았다.

먼저 알 개념

  • 시험 당시 적용할 직접 법령은 소득세법 제17조, 소득세법 제43조이다.
  • 배당소득은 법인이나 법인으로 보는 단체로부터의 이익분배 등을 말한다.
  • 쟁점별 검산: 동업계약, 손익분배, 지분이전 약정, 공탁금출급권 소송과 2억,1억 정산근거를 확인한다.
  • 사실포섭,소결: 3억 원 중 2억 원이 출자원본 반환이고 1억 원이 지분이전 지연에 대한 정산,손해배상이라면 계약,판결의 산정근거를 각각 추적한다.
  • 증빙,세무조사 활용: 동업계약, 손익분배, 지분이전 약정, 공탁금출급권 소송과 2억,1억 정산근거를 확인한다.

헷갈리기 쉬운 점

  • 먼저 표시할 사실: 甲은 2억 원을 출자하고 乙과 부동산매매업을 직접 공동 수행하며 손익을 나눠 가졌다. 이 사실이 적용 범위를 가른다.
  • 따로 확인할 사실: 2017년 4월 동업을 끝내며 乙 소유 과수원을 甲의 출자금 2억 원 반환에 갈음하여 이전하기로 했다. 앞 사실과 섞지 않고 별도로 판단한다.
  • 현행 대조: 공동사업 종료 정산금의 배당소득 해당 여부 — 시험일 기준: ; 소득세법 제17조. 2026-08-29 현재 확인 항목: 공동사업 정산금과 배당소득의 구별 및 지연손해금 과세 현행 해석기준. 이 기록은 시험일 시행본을 고정하며, 2026 세무조정 결론은 해당 최신 개정문 대조 후 정한다.

04

완성형 학습용 모범답안

학습용 모범답안이며 공식답안이 아님Q-Net 공식 채점기준이 아님
문단 1 · 쟁점

甲은 乙과 부동산매매업을 직접 공동 영위하고 손익을 나눠 가진 공동사업자이다. 탈퇴 시 출자금 2억 원 반환에 갈음하여 받기로 한 과수원이 수용되어 3억 원을 받은 경우, 초과 1억 원이 배당소득인지가 문제다.

문단 2 · 법령·법리

소득세법상 배당소득에는 법인의 이익배당과 법인으로 보는 단체의 분배금, 공동사업에 자본만 출자하고 경영에 참여하지 않는 출자공동사업자의 손익분배액 등이 포함된다. 사업을 직접 공동 수행한 자의 사업소득이나 사업종료 후 대물로 취득한 자산의 양도차익은 그 본래 소득유형으로 판정한다. 시험연도 적용근거는 소득세법 제17조이다.

문단 3 · 사실 포섭

동업계약서와 부동산 거래내역은 甲이 2억 원을 출자하고 乙과 여러 차례 매매에 직접 참여했음을 보여 주므로 단순 출자공동사업자가 아니다. 2017년 4월 청산합의서, 과수원 수용재결과 판결문 및 3억 원 공탁기록을 대사하면, 그 돈은 공동사업 이익의 분배가 아니라 출자금 반환용 과수원의 수용대가이다.

문단 4 · 계산

2억 원은 출자원본을 과수원으로 반환받은 취득가액에 해당하고, 3억 원은 과수원의 수용대가다. 따라서 1억 원은 3억 원에서 2억 원과 법정 필요경비를 빼는 양도소득 계산으로 검토할 금액이지, 공동사업의 이익배당액이 아니다.

문단 5 · 결론

甲은 경영에 참여한 공동사업자이고, 1억 원은 탈퇴 후 출자금 반환용 과수원이 수용되어 생긴 양도차익이다. 이를 동업관계 탈퇴에 따른 배당소득으로 본 증액경정은 소득유형을 잘못 적용하여 위법하다.

05

초보자용 답안 해설

문단 1 · 쟁점

왜 필요한가요?

자료 대조 소득세법 제17조의 원칙을 정리축으로 적는다. 예외는 “2억의 정리축”에서 찾는다. 공동사업 종료 정산금의 배당소득 해당 여부의 결론은 확인축으로 확정한다.

쉬운 말로

기억할 때 공동사업 종료 정산금의 배당소득 해당 여부를 정리축으로 기억한다. 소득세법 제17조에서 확인축을 찾는다. “2017년의 확인축” 자료를 정리축으로 확인한다.

문단 2 · 법령·법리

왜 필요한가요?

세무조사 “2017년의 적용축”라는 사실을 적용축으로 잡는다. 소득세법 제43조의 요건은 주체선에서 확인한다. 공동사업 종료 정산금의 배당소득 해당 여부의 효과를 기준점으로 분해한다.

쉬운 말로

과세 확인 공동사업 종료 정산금의 배당소득 해당 여부를 적용축으로 기억한다. 소득세법 제43조에서 주체선을 찾는다. “소유권이전의 주체선” 자료를 기준점으로 확인한다.

문단 3 · 사실 포섭

왜 필요한가요?

사례 메모 공동사업 종료 정산금의 배당소득 해당 여부를 금액표로 설명한다. 소득세법 제17조에서 조사표를 읽는다. 세무조사에서는 “소유권이전의 금액표” 자료를 기간표로 확정한다.

쉬운 말로

계산 전 공동사업 종료 정산금의 배당소득 해당 여부의 계산표를 금액표로 만든다. “2억의 조사표”에서 수치를 조사표로 옮긴다. 소득세법 제17조를 기준으로 검산한다.

문단 4 · 계산

왜 필요한가요?

장부 대조 공동사업 종료 정산금의 배당소득 해당 여부를 수치표로 대조한다. 소득세법 제43조에서 기준표를 읽는다. 세무조사에서는 “2억의 수치표” 자료를 세율표로 검증한다.

쉬운 말로

소득 구분 소득세법 제43조가 정한 수치표를 읽는다. 공동사업 종료 정산금의 배당소득 해당 여부에 “2017년의 기준표” 자료를 기준표로 대입한다. 결과는 세율표로 적는다.

문단 5 · 결론

왜 필요한가요?

주체 확인 공동사업 종료 정산금의 배당소득 해당 여부와 “2017년의 문장축”의 연결을 문장축으로 대조한다. 소득세법 제17조와 사실축을 읽는다. 조사자료는 판정선으로 확인한다.

쉬운 말로

판정 마무리 세무조사에서는 “소유권이전의 사실축” 증빙을 문장축으로 찾는다. 공동사업 종료 정산금의 배당소득 해당 여부가 소득세법 제17조 선에서 정한다. 판정선에서 결론은 사실축으로 기록한다.

자주 하는 실수

  • 답안에서 빠지기 쉬운 내용은 [공동사업 종료 정산금의 배당소득 해당 여부에서 소득세법 제17조 및 공동사업 정산금 법해석의 적용시점과 법정요건을 쓰지 않는 것]이다. 관련 법령인 소득세법 제17조의 요건과 공동사업 종료 정산금의 배당소득 해당 여부의 효과까지 적어야 결론이 완성된다.
  • 답안에서 빠지기 쉬운 내용은 [공동사업 종료 정산금의 배당소득 해당 여부의 소결에 이르는 핵심 사실과 반대사실을 증빙에 연결]이다. 관련 법령인 소득세법 제17조의 요건과 공동사업 종료 정산금의 배당소득 해당 여부의 효과까지 적어야 결론이 완성된다.

변형 연습문제

정산금이 법인의 잉여금 배당으로 결의된 경우로 바꾼다.
