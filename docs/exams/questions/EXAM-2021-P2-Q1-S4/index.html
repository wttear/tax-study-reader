02

초보자용 문제 읽기

무엇을 답해야 하나요?

등록증은 있으나 독립사업자가 아닌 병이 실제 공급 없이 세금계산서를 발행한 경우 부과근거와 취지를 설명한다.

핵심 사실

  • 丙은 관할 세무서장으로부터 사업자등록증(일반과세자)을 발급받고, 세금계산서 (공급가액 1억 원, 세액 1천만 원)를 사업자인 丁에게 발급한 후, 부가가치세를 신고,납부하였다.
  • 부가가치세법 제60조 제4항은 사업자가 아닌 자가 재화,용역 공급 없이 세금계산서를 발급한 경우에도 발급자를 사업자로 보아 공급가액의 3% 가산세를 부과한다.

먼저 알 개념

  • 시험 당시 적용할 직접 법령은 부가가치세법 제60조, 부가가치세법 제60조 제4항, 부가가치세법 제32조이다.
  • 부가가치세법 제60조 제4항은 사업자가 아닌 자가 재화,용역 공급 없이 세금계산서를 발급한 경우에도 발급자를 사업자로 보아 공급가액의 3% 가산세를 부과한다.
  • 산식: 무거래 발급 가산세=기재 공급가액 1억 원×3%=300만 원.
  • 사실포섭,소결: 사업자등록증만 가진 丙에게 인력,재고,물류,대금흐름이 없어 공급사실이 확인되지 않는다.
  • 증빙,세무조사 활용: 사업장,인력,재고, 대금,물류 부재, 발급세액 1천만 원과 신고납부 내역을 확인한다.

헷갈리기 쉬운 점

  • 먼저 표시할 사실: 丙은 관할 세무서장으로부터 사업자등록증(일반과세자)을 발급받고, 세금계산서 (공급가액 1억 원, 세액 1천만 원)를 사업자인 丁에게 발급한 후, 부가가치세를 신고,납부하였다. 이 사실이 적용 범위를 가른다.
  • 따로 확인할 사실: 부가가치세법 제60조 제4항은 사업자가 아닌 자가 재화,용역 공급 없이 세금계산서를 발급한 경우에도 발급자를 사업자로 보아 공급가액의 3% 가산세를 부과한다. 앞 사실과 섞지 않고 별도로 판단한다.
  • 현행 대조: 사업자가 아닌 자의 무거래 세금계산서 발행 제재 — 시험일 기준: ; 부가가치세법 제60조의 무거래 세금계산서 제재. 2026-08-29 현재 확인 항목: 사업자 아닌 자의 무거래 발급 가산세율,부정행위 제재와 현행 조문 확인. 이 기록은 시험일 시행본을 고정하며, 2026 계산 결론은 해당 최신 세율,한도 대조 후 정한다.

  4. 증빙,세무조사 활용: 사업장,인력,재고, 대금,물류 부재, 발급세액 1천만 원과 신고납부 내역을 확인한다.
04

완성형 학습용 모범답안

학습용 모범답안이며 공식답안이 아님Q-Net 공식 채점기준이 아님
문단 1 · 쟁점

쟁점은 사업자가 아닌 자의 무거래 세금계산서 발행 제재: 등록증은 있으나 독립사업자가 아닌 병이 실제 공급 없이 세금계산서를 발행한 경우 부과근거와 취지를 설명한다.

문단 2 · 법령·법리

법리·법정요건: 부가가치세법 제60조 제4항은 사업자가 아닌 자가 재화·용역 공급 없이 세금계산서를 발급한 경우에도 발급자를 사업자로 보아 공급가액의 3% 가산세를 부과한다. 실제 공급이 없으므로 발급자 매출세액과 상대방 매입세액은 인정되지 않는다.

문단 3 · 계산

무거래 발급 가산세=기재 공급가액 1억 원×3%=300만 원. 발급자의 실제 공급분 납부세액 0원, 상대방 매입세액 불공제 1,000만 원이다.

문단 4 · 사실 포섭

증빙·세무조사 활용: 사업장·인력·재고, 대금·물류 부재, 발급세액 1천만 원과 신고납부 내역을 확인한다.

문단 5 · 결론

사실포섭·소결: 사업자등록증만 가진 丙에게 인력·재고·물류·대금흐름이 없어 공급사실이 확인되지 않는다. 제60조 제4항 가산세 300만 원을 부과하되, 丙이 낸 1,000만 원을 실제 매출세액으로 확정하지 않고 丁의 1,000만 원 매입세액도 불공제한다.

05

초보자용 답안 해설

문단 1 · 쟁점

왜 필요한가요?

기초부터 사업자가 아닌 자의 무거래 세금계산서 발행의 판단 질문을 조문표로 만든다. “관할의 조문표” 자료를 조문표로 확인한다. 부가가치세법 제60조 근거는 답안에 세율표로 남긴다.

쉬운 말로

사실부터 사업자가 아닌 자의 무거래 세금계산서 발행의 원칙과 예외를 조문표로 가른다. “부가가치세법의 조문표” 자료를 조문표로 살핀다. 부가가치세법 제60조로 효과를 설명한다.

문단 2 · 법령·법리

왜 필요한가요?

서류 수령 사업자가 아닌 자의 무거래 세금계산서 발행을 사례표로 고정한다. 부가가치세법 제60조제4항에서 정리축을 읽는다. 세무조사에서는 “부가가치세법의 사례표” 자료를 계산칸으로 살핀다.

쉬운 말로

실무에서는 “관할의 정리축”라는 사실을 사례표로 표시한다. 사업자가 아닌 자의 무거래 세금계산서 발행이 부가가치세법 제60조제4항의 범위에서 판단한다. 계산칸에서 증빙은 정리축으로 맞춘다.

문단 3 · 계산

왜 필요한가요?

실무 검토 사업자가 아닌 자의 무거래 세금계산서 발행을 판정선으로 분리한다. 부가가치세법 제32조에서 순서표를 읽는다. 세무조사에서는 “관할의 판정선” 자료를 예외표로 교차한다.

쉬운 말로

기간 점검 부가가치세법 제32조가 정한 판정선을 읽는다. 사업자가 아닌 자의 무거래 세금계산서 발행에 “부가가치세법의 순서표” 자료를 순서표로 대입한다. 결과는 예외표로 적는다.

문단 4 · 사실 포섭

왜 필요한가요?

재검토 부가가치세법 제60조의 원칙을 대조축으로 적는다. 예외는 “부가가치세법의 대조축”에서 찾는다. 사업자가 아닌 자의 무거래 세금계산서 발행의 결론은 주체선으로 확정한다.

쉬운 말로

실무에서는 사업자가 아닌 자의 무거래 세금계산서 발행을 대조축으로 기억한다. 부가가치세법 제60조에서 주체선을 찾는다. “관할의 주체선” 자료를 기록표로 확인한다.

문단 5 · 결론

왜 필요한가요?

기초부터 부가가치세법 제60조제4항이 정한 요건표를 먼저 본다. 사업자가 아닌 자의 무거래 세금계산서 발행에 “관할의 요건표” 자료를 효과표로 옮긴다. 확인축에서 결론은 부가가치세법 제60조제4항을 근거로 잡는다.

쉬운 말로

두 번째 사업자가 아닌 자의 무거래 세금계산서 발행을 요건표로 기억한다. 부가가치세법 제60조제4항에서 효과표를 찾는다. “부가가치세법의 효과표” 자료를 확인축으로 확인한다.

가산세와 정당한 사유

국세기본법

사업자가 아닌 자의 무거래 세금계산서 발행 제재를 검토할 때 부가가치세법 제60조 문언과 결론축 사례를 비교한다. “관할의 기록표” 자료는 기록표로 확인한다.

자주 하는 실수

  • 답안에서 빠지기 쉬운 내용은 [사업자가 아닌 자의 무거래 세금계산서 발행 제재에서 부가가치세법 제60조의 무거래 세금계산서 제재의 적용시점과 법정요건을 쓰지 않는 것]이다. 관련 법령인 부가가치세법 제60조의 요건과 사업자가 아닌 자의 무거래 세금계산서 발행 제재의 효과까지 적어야 결론이 완성된다.
  • 답안에서 빠지기 쉬운 내용은 [사업자가 아닌 자의 무거래 세금계산서 발행 제재의 소결에 이르는 핵심 사실과 반대사실을 증빙에 연결]이다. 관련 법령인 부가가치세법 제60조의 요건과 사업자가 아닌 자의 무거래 세금계산서 발행 제재의 효과까지 적어야 결론이 완성된다.
