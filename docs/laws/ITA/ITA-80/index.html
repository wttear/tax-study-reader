초보자용 해설

장부 일부가 허위여도 남은 장부·금융·재고자료로 소득을 계산할 수 있으면 실지조사로 그 부분만 고친다. 중요한 부분이 미비·허위여서 실제 소득 계산이 불가능할 때만 법정 추계결정 사유와 방법을 검토한다.

계약·계좌 명의와 실제로 소득을 지배·관리·향유한 사람이 다를 수 있지만 명의 불일치만으로 귀속을 바꾸지는 않는다. 출자·의사결정·계좌통제·독립 실체·개인사용을 묶어 특정 실질귀속자를 입증한다.
