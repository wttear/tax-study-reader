1. 오늘의 목표와 30초 쉬운 설명 — 2분

쉬운 설명

30초 쉬운 설명

국외로 돈을 보낸다는 사실만으로 원천징수율을 정할 수 없다. 먼저 상대국과 적용 가능한 조세조약이 있는지, 국내법상 어떤 국내원천소득인지, 돈을 받는 명의자가 실제 소득의 귀속자인지, 제한세율을 적용할 서류가 갖춰졌는지를 순서대로 확인한다.

계약 이름이 사용료·용역비·물품대금 중 무엇인지보다 실제 권리와 수행장소가 중요하다. 지급일과 환율, 총액·순액 약정도 원천징수세액을 바꾼다.

오늘의 목표

오늘 할 수 있어야 하는 것

  • 외국법인의 국내원천 사용료와 사업소득·인적용역·물품대금을 구분한다.
  • 국내원천 사용료 100000에 문제 제시 원천징수율 20퍼센트를 적용한다.
  • 계약·소득세법 시행규칙 별지 제21호서식 원천징수이행상황신고서·국외지급자료와 실질귀속자·제한세율 서류를 대사한다.

먼저 판단하기

시작 전 판단

비식별 AA법인이 외국법인에 “기술지원비” 100000을 지급한다. 계약에는 국내에서 특허 제조공정을 반복 사용할 권리도 들어 있다. 명칭만 보고 용역비로 처리할지 실제 권리를 분해할지 예측하자.

2. 핵심 용어와 법적 판단지도 — 4분

핵심 용어

핵심 용어

국내원천소득 한국과 과세 연결점이 있는 소득 법인세법 제93조 유형별 판단 권리 사용지·수행지

법적 판단지도

소득구분 국내 특허 반복사용 계약·권리명세 독립 용역 결과물 사용료 후보
실질귀속 수취인이 처분·위험 부담 지배구조·계좌·재송금 도관회사 추가 확인
세율·서류 문제 제시 국내법 20퍼센트 법령검토·신청서 제한세율 적용 20000 후보

판단 순서는 조세조약 적용 여부 → 국내법상 소득구분 → 실질귀속자 → 제한세율 서류이다.

  1. 조세조약의 존재·대상자·소득조항을 먼저 확인하되, 이 합성 사례에는 적용 조세조약 없음이 전제다.
  2. 2026. 7. 1. 시행 법인세법 제93조로 국내원천 사용료인지 판단하고 국내사업장 귀속 여부를 구분한다.
  3. 법인세법 제98조와 2026. 2. 27. 시행 법인세법 시행령 제132조로 지급시기·과세표준·원천징수를 확인한다.
  4. 시행령 제138조의7의 제한세율 신청을 검토하고, 법인세법 제120조의2·법인세법 시행령 제162조의2의 지급명세서 의무와 소득유형별 서식을 확인한다. 합성 사례의 지급소득은 사용료소득이므로 소득세법 시행규칙 별지 제23호서식(5) 비거주자의 사업·선박등 임대·사용료·인적용역·기타소득 지급명세서에 연결한다. 이 서식은 법인세법 시행규칙 제82조 제18항 준용(법 제120조의2·영 제162조의2 관련)으로 사용하며, 조약이 없으므로 제한세율은 적용하지 않는다.

심화 펼치기

심화

조세조약이 존재해도 명의상 수취인이 실질귀속자가 아니거나 제한세율 서류가 법정요건을 충족하지 못하면 적용 결과가 달라질 수 있다. 반대로 서류 미비와 실질귀속 부재를 같은 이유로 쓰지 않는다. 지급 뒤 경정청구 가능성도 적용연도 절차에 따라 별도 검토한다.

3. 완성된 쉬운 예제 — 4분

사실

AA법인은 2026년 8월 31일 외국법인에게 국내 공장에서 사용할 특허 라이선스 대가 100000을 지급한다. 합성 상대국에는 적용 조세조약 없음이 명시돼 있다. 수취 외국법인이 계약·권리·대금의 실질귀속자이고 국내사업장은 없다. 문제는 국내법상 원천징수율을 20퍼센트로 준다.

먼저 설명하기

자기설명

조약 검토, 국내원천 사용료 분류, 실질귀속자, 세율·서류, 지급일 세액과 신고를 순서대로 말해 보자.

전문가 판단 과정

판단 단계 합성 입력 결과
조세조약 적용 조세조약 없음 제한세율 미적용
국내법 분류 국내 특허 사용 국내원천 사용료

문제 세율 20퍼센트 교육 계산에만 사용

이 주제는 지급자료와 원천징수 신고를 대사하는 절차다. 분개를 억지로 만들지 않고 계약상 권리·실질귀속·지급일·신고세액을 추적한다.

국내원천 사용료 100000 × 문제 제시 원천징수율 20퍼센트 = 원천징수세액 20000이다. 합성 범위의 지급총액 100000에서 원천징수세액 20000을 빼면 송금액은 80000이다. 실제 신고에서는 조약·국내사업장·총액화 약정·지방소득세·환율과 법정세율을 지급일 기준으로 다시 확인한다.

원시증빙 전표·장부 시산표·재무제표 신고서·납부자료 대사 결과
특허라이선스계약서·외화송금 금융거래·실질귀속자 확인자료 사용료 계정별원장·외국법인별 원천징수 보조원장 합계잔액시산표 사용료 100000과 현금흐름표 국외송금액 소득세법 시행규칙 별지 제21호서식 원천징수이행상황신고서·납부서와 소득세법 시행규칙 별지 제23호서식(5) 비거주자의 사업·선박등 임대·사용료·인적용역·기타소득 지급명세서 — 법인세법 시행규칙 제82조 제18항 준용(법 제120조의2·영 제162조의2 관련) 지급 금액 100000·원천징수세액 20000·송금액 80000 및 지급일의 일치 확인

4. 세무조사 증빙 실습 — 8분

결론을 가린 사건

비식별 AB법인은 조약 체결국의 중간회사를 통해 국외 본사에 소프트웨어 대가를 지급했다. 중간회사는 대금 수령 다음 날 98퍼센트를 본사에 재송금하며 계약변경권과 신용위험이 없다. 납세자는 중간회사 거주자증명서와 제한세율 신청서를 냈다.

경쟁 가설

경쟁 가설

  • 조사 가설: 과세관청은 중간회사가 소득을 지배·향유하지 못하는 도관이므로 실질귀속자와 적용 조약·세율을 본사 기준으로 다시 보아야 한다고 판단한다.
  • 납세자 가설: 납세자는 중간회사가 지역 라이선스를 관리하고 계약당사자로서 법적 책임을 져 조약상 실질귀속자라고 본다.

증빙 판단표

법적 요건 주장 사실 확인 자료 지지하는 실제 가설 신뢰도·공백 추가 확인
소득구분 소프트웨어 사용권 대가 계약·권리목록 두 가설 공통 용역 혼재 기능별 대가 분리
조약 대상 중간회사 거주지 거주자증명·조세조약 납세자 가설 형식 주소 실질 사업장 확인
실질귀속자 98퍼센트 즉시 재송금 계좌·국외지급자료 조사 가설 관리수수료 주장 처분권·위험 검증
계약 기능 지역 라이선스 관리 계약·직원·회의자료 납세자 가설 인력 적음 의사결정 로그 확인
제한세율 신청서 제출 원천징수신고서·신청서 납세자 가설 귀속자 불일치 가능 수익자별 서류 대사

먼저 판단하기

학습자 잠정 결론

  • 잠정 결론: 거주자증명서만으로 끝내지 않고 중간회사의 처분권·인력·위험·재송금 의무를 확인해 실질귀속자를 정한다.
  • 결정적 사실: 중간회사가 대금을 본사에 보낼 법적·사실상 의무 없이 자체 사업판단으로 사용했는지다.
  • 추가로 필요한 증빙: 전체 계약망, 계좌, 국외지급자료, 이사회·직원자료, 거주자증명, 제한세율 신청서와 본사 정산서다.
전문가 피드백 펼치기

전문가 피드백

과세관청은 재송금 비율만으로 도관을 확정하지 말고 계약권한과 위험을 확인한다. 납세자는 계약 명의와 서류 제출 외에 실제 의사결정·인력·자금 사용을 보여야 한다.

  • 제한세율 적용 가능: 조약상 거주자이며 실질 지배·향유, 기능·위험과 법정 서류가 모두 확인되는 경우
  • 추가 확인 필요: 운영기능은 있으나 자동 재송금과 계약권한 제한이 혼재하는 경우
  • 제한세율 적용 곤란: 명의만 보유하고 즉시 재송금 의무가 있으며 실질 기능·위험이 없는 경우

5. 세무사 2차 연결 — 3분

답안 뼈대

  • 쟁점: 외국법인에게 지급한 특허대가의 국내원천소득 분류와 원천징수세액이다.
  • 법리: 조약 적용 여부, 국내법상 소득구분, 실질귀속자, 제한세율 서류 순서로 판단한다.
  • 사실포섭: 적용 조약이 없고 국내 특허 사용료 100000이며 수취인이 실질귀속자, 문제 세율은 20퍼센트다.
  • 결론: 합성 전제에서 원천징수세액 20000을 지급일 기준 신고·납부한다.

원천징수 지급액×적용세율, 별지 제21호서식 원천징수이행상황신고서·소득세법 시행규칙 별지 제23호서식(5) 사용료소득 지급명세서(법인세법 시행규칙 제82조 제18항 준용)

계약 명칭보다 사용권의 실질을 포섭하고, 조약이 없다는 가정과 국내법 20퍼센트라는 교육 입력을 명시한다.

감점 방지

  • 국외송금이라는 이유만으로 국내원천소득이라고 단정하지 않는다.
  • 사용료·사업소득·인적용역·물품대금을 구분하지 않은 채 세율부터 쓰지 않는다.
