1. 오늘의 목표와 30초 쉬운 설명 — 2분

쉬운 설명

30초 쉬운 설명

돈이 실제로 지급되고 회계상 비용으로 기록되었다고 세법상 손금이 자동 확정되지는 않는다. 법인세법 제19조는 법인의 사업과 관련하여 발생한 통상적인 비용이거나 수익과 직접 관련된 비용인지를 묻는다.

업무관련성은 계약 제목이 아니라 누가 어떤 업무를 수행했고 법인이 어떤 경제적 효익을 얻었는지로 판단한다. 사회질서를 위반한 지출은 2025두36013이 제시한 좁은 법리와 구체적 규제 목적을 확인해야 하며 모든 위법 지출을 한 문장으로 처리해서는 안 된다.

오늘의 목표

오늘 할 수 있어야 하는 것

  • 순자산 감소, 사업관련성, 통상성·수익 직접관련성을 순서대로 판단한다.
  • 개인주택 자문료 45000의 손금불산입과 대표자 상여를 계산한다.
  • 2025두36013의 보험모집 규제 사실과 2015~2019년 적용법을 정확히 한정한다.

심화

2025두36013은 보험모집 질서를 정면으로 위반한 특정 지급을 손금으로 보지 않은 판결이다. 지출의 위법성이 언급된 다른 사건은 관련 법률의 목적, 위반 정도, 수익과의 관계, 후속 판례를 따로 확인한다. 민사상 계약이 유효한지와 법인세 손금인지도 서로 다른 질문이다.

4. 세무조사 증빙 실습 — 8분

결론을 가린 사건

X법인은 해외시장 자문료 76000을 지급했다. 계약서는 2쪽이고 최종 보고서는 없지만, 자문역이 소개한 현지 유통사와 6개월 뒤 300000의 수출계약이 체결됐다. 조사팀은 성과물이 없다고 보고, 회사는 소개·협상 자문이 실제 있었다고 주장한다.

경쟁 가설

보고서가 없다는 한 사실과 후속 매출이 있다는 한 사실 중 어느 것도 단독으로 결론을 정하지 않는다.

5. 세무사 2차 연결 — 3분

답안 뼈대

  • 쟁점: 지급수수료 45000이 제19조상 법인 업무 관련 손비인지 여부다.
  • 법리: 손비는 사업과 관련하여 발생한 통상적인 비용이거나 수익과 직접 관련된 비용이어야 한다.
  • 사실포섭: 용역 대상은 대표 개인주택이고 법인은 사용권이나 수익효과를 얻지 못했다.

심화 펼치기

심화

사회질서 위반 지출 문제라면 어떤 산업규제가 누구의 이익을 보호하고 어떤 행위를 금지하는지까지 써야 판례 포섭이 된다.

감점 방지

  • 실제 지급과 세법상 손금성을 같은 판단으로 쓰지 않는다.
  • 업무관련성증빙을 세금계산서 한 장으로 끝내지 않는다.
  • 모든 위법 지출이 언제나 손금불산입이라고 일반화하지 않는다.
  • 판례 사건시기 구 보험업법을 2026년 거래에 소급하지 않는다.
  • 귀속자 확인 없이 상여·기타사외유출을 선택하지 않는다.

6. 중요 판례 예측과 해설 — 5분

판례를 먼저 쉽게

대법원 2026. 4. 30. 선고 2025두36013은 보험대리점이 2015년부터 2019년 사이 모집자격이 없거나 다른 보험대리점에 소속된 설계사 등에게 지급한 2,658,021,870원의 손금성이 문제 된 사건이다.

먼저 예측하기

결론 전 예측

보험모집 수익을 얻는 데 실제 기여한 지급이라도 보험모집의 기본 질서를 정면으로 위반한 대가라면 통상비용 또는 수익 직접관련 비용으로 인정될지 예측하자.

판례 결론과 이유 펼치기

법원 결론과 이유

  • 주문·결론: 상고를 모두 기각한다. 상고비용은 원고가 부담한다.
  • 핵심 법리: 통상적인 비용은 같은 업종의 다른 법인도 같은 상황에서 지출할 비용인지 경위·목적·형태·금액·효과를 종합해 판단하며, 특별한 사정이 없는 사회질서 위반 지출은 제외된다.
  • 사실포섭: 보험모집 자격·소속 규제를 정면으로 위반한 수수료는 보험업의 건전한 모집질서와 계약자 보호에 역행하여 통상비용이나 수익 직접관련 비용이 아니라고 보았다.
