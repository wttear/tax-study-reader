1. 오늘의 목표와 30초 쉬운 설명 — 2분

쉬운 설명

30초 쉬운 설명

가공매입은 물건이나 용역을 실제로 받지 않고 비용증빙만 만든 경우다. 위장매입은 물건은 실제로 받았지만 세금계산서에 적힌 공급자가 진짜 공급자와 다른 경우다. 둘 다 증빙 문제가 있지만 법인세 손금 결론이 항상 같지는 않다.

가공매입은 실물과 업무관련 비용이 없으므로 손금불산입 가능성이 높다. 위장매입은 실제 원가와 지급이 객관적으로 확인되면 법인세 손금은 인정될 여지가 있지만 부가가치세 매입세액 공제와 증빙 관련 제재는 별도로 검토한다.

오늘 할 수 있어야 하는 것

  • 장부 비용 60000과 세법상 손금 0의 차이를 소득처분까지 연결한다.
  • 매입원장·세금계산서·거래처 자료를 신고서까지 대사한다.

3. 완성된 쉬운 예제 — 4분

사실

G법인은 2026년 9월 공급가액 60000, 매입세액 6000의 전자세금계산서를 받아 비용과 부가세대급금으로 기록했다. 입고·운송·검수·용역 산출물은 없고 지급액 66000은 당일 대표자 측 계좌로 이동해 개인적으로 사용되었다.

4. 세무조사 증빙 실습 — 8분

결론을 가린 사건

H법인은 매입처 X의 세금계산서 44000을 장부에 반영했다. X 창고에는 물품이 없었지만 운송장은 Y 창고에서 H 공장으로 직접 배송되었다고 표시하고, 생산일보에는 같은 규격 원재료 투입이 있다. 대금은 X를 거쳐 Y에게 이체되었다.

직송은 판매자가 자기 창고를 거치지 않고 다른 곳에서 구매자에게 바로 보내는 방식이므로 입고지가 X가 아니라는 사실만으로 가공거래가 되는 것은 아니다.

경쟁 가설

경쟁 가설

  • 조사 가설: 과세관청은 X가 자료상이고 운송장도 사후 작성되어 실거래 없이 비용과 매입세액을 만든 가공매입이라고 본다.
  • 납세자 가설: 납세자는 Y가 실제 공급한 원재료를 X 명의로 받은 위장매입일 뿐 생산 투입 원가는 실제 발생했다고 본다.

가공인지 위장인지에 따라 법인세 원가 40000의 결론이 달라지므로 문서 명의보다 실물·생산·대금의 연속성을 본다.

법적 요건 주장 사실 확인 자료 지지하는 실제 가설 신뢰도·공백 추가 확인
실물 이동 Y에서 H로 직송 매입원장·운송장 납세자 가설 운송장 원본시각 공백 운송사 GPS·배차 로그 확인
증빙 명의 X가 세금계산서 발행 세금계산서·거래처 등록 조사 가설 중개계약 유무 공백 X-Y-H 계약과 수수료 확인

대금 최종 귀속 X를 거쳐 Y가 수령 금융·거래처 계좌 납세자 가설 반환·순환거래 공백 Y 이후 자금흐름 확인

현재 자료는 실제 원가 존재에는 힘을 주지만 세금계산서 공급자 동일성 문제는 남는다.

전문가 피드백 펼치기

전문가 피드백

납세자는 운송·생산·재고·대금이 같은 수량과 날짜로 이어져야 실제 원가를 입증할 수 있다. 위장매입이면 실제 공급자 Y와 지급액을 특정해야 한다.

조사팀은 X가 자료상이라는 사실만으로 H의 실제 원재료 원가까지 자동 부인해서는 안 된다. 반대로 생산일보가 사후 수정됐는지 전산 이력을 확인해야 한다.

  • 과세 가능: 운송·생산 투입이 없고 대금이 되돌아온 경우
  • 추가 확인 필요: 실물은 보이나 공급자·단가 계약이 불명확한 경우
  • 과세 곤란: 실제 원재료와 지급액이 독립자료로 확인되어 법인세 원가가 입증되는 경우

처분서에는 법인세 손금, 부가가치세 공제, 증빙 관련 제재를 세목과 요건별로 나누어 적는다.

5. 세무사 2차 연결 — 3분

답안 뼈대

  • 쟁점: 세금계산서상 매입 60000이 가공인지 위장인지와 손금·소득처분 효과다.
  • 법리: 손금은 업무관련 실제 비용이어야 하며 사실과 다른 증빙이 있어도 실제 원가 입증 여부를 별도 판단한다.
  • 사실포섭: 실물·용역이 없고 대금이 대표자 측에 귀속되어 실제 비용이 아니다.
  • 결론: 손금불산입 60000 상여, 매입세액 6000은 별도 불공제 검토다.

  • 서술 연결: 대표자에게 사외유출된 60000을 소득금액조정합계표 손금불산입·상여란에 가산하고 부가가치세 신고서 매입세액에서 6000을 제외한다.
심화 펼치기

심화

가공·위장 구별 문단 뒤에 법인세와 부가가치세 효과를 별도 문단으로 쓰면 세목을 섞는 오류를 줄일 수 있다.

감점 방지

  • 세금계산서 명의 오류와 실거래 부재를 동일시하지 않는다.
  • 부가가치세 불공제를 법인세 손금불산입의 자동 근거로 쓰지 않는다.
  • 실제 원가를 주장하는 납세자의 입증자료도 평가한다.
  • 대금 귀속 없이 대표자 상여를 단정하지 않는다.
  • 공급가액과 매입세액을 중복 가산하지 않는다.

정답은 거래 명칭보다 실물흐름과 대금 최종 귀속을 사실에 포섭하는 데서 나온다.
