1. 오늘의 목표와 30초 쉬운 설명 — 2분

쉬운 설명

30초 쉬운 설명

돈을 밖으로 지급했다는 모습이 같아도 대가관계가 없으면 기부금, 특정 거래관계의 원활화를 위한 지출이면 기업업무추진비, 공개된 조건 아래 불특정 다수의 구매를 유도하면 판매촉진비가 될 수 있다. 이름이 아니라 수령자 범위와 지급 조건을 먼저 본다.

기부금과 기업업무추진비에는 각각의 한도·명세가 있고, 판매촉진비는 실제 판매활동과 통상성이 입증되어야 한다. 한 분류의 초과액을 다른 분류의 한도로 밀어 넣으면 안 된다.

오늘의 목표

오늘 할 수 있어야 하는 것

  • 불특정 다수, 특정 거래처, 대가 없는 출연이라는 세 갈래로 비용을 분류한다.
  • 장부 비용 40000에서 세법상 인정 32000과 손금불산입 8000을 다시 계산한다.
  • 기부금 조정명세서와 기업업무추진비 조정명세서를 원장별로 연결한다.

먼저 판단하기

시작 전 판단

비식별 A법인이 지역행사 후원금, 주요 거래처 선물, 모든 구매자 대상 쿠폰을 모두 광고선전비로 기록했다. 계정명 하나만 보고 전액 판매촉진비라고 할 수 있는지 결론을 가린 채 세 지급의 상대방과 조건을 나눠 보자.

핵심 용어

심화 펼치기

심화

판매촉진계약이 있어도 실제 수령자가 특정 거래처 임직원뿐이면 계약 명칭보다 집행자료가 우선한다. 반대로 거래처가 일부 포함되더라도 객관적 구매조건을 충족한 모든 고객에게 동일하게 지급했다면 불특정 다수 판촉이라는 가설이 강해진다.

3. 완성된 쉬운 예제 — 4분

사실

A법인은 2026년 지정 기부처에 10000, 특정 거래처 담당자 선물에 12000, 공개된 구매행사 쿠폰에 18000을 지출했다. 교육문제는 다른 한도 요소를 이미 반영한 기부금 인정액을 6000, 기업업무추진비 인정액을 8000으로 주고 쿠폰 18000은 전액 업무관련성이 확인되었다고 한다.

먼저 설명하기

자기설명

세 항목의 분류, 각 인정액, 손금불산입, 차이의 성격과 신고서 위치를 말해 보자.

전문가 판단 과정

특정 거래처 선물 12000 8000 4000 기업업무추진비 조정명세서
불특정 다수 쿠폰 18000 18000 0 판매촉진비 원장 대사

이 주제는 이미 지출된 비용을 수령자·대가·공개조건에 따라 분류하는 신고 대사다. 분개를 억지로 만들지 않고 원시증빙과 원장을 조정명세서에 연결한다.

장부 비용 40000 - 세법상 인정 32000 = 손금불산입 8000이다. 한도초과 8000은 이 사례에서 미래 사업연도에 자동 추인하지 않는 영구적 차이이며, 사외유출된 지출의 법정 소득처분을 분류별로 확인한다. 교육문제에서 제시한 인정액을 쓴 것이므로 현행 한도율을 이 숫자에서 역산하지 않는다.

원시증빙 전표·장부 시산표·재무제표 신고서·납부자료 대사 결과
기부금영수증·거래처 수령서·판매촉진계약서와 쿠폰 로그 기부금·기업업무추진비·광고선전비 계정별원장 합계 40000 합계잔액시산표와 손익계산서 판매관리비 40000 법인세 신고서의 기부금 조정명세서·기업업무추진비 조정명세서 인정금액 6000+8000+18000=32000, 두 한도초과액 4000+4000=8000 조정 확인

4. 세무조사 증빙 실습 — 8분

결론을 가린 사건

비식별 B법인은 신제품 출시 때 상품권 54000을 지급했다. 행사계획에는 모든 구매고객 대상이라고 적었지만 실제 배부목록의 절반은 상위 거래처 담당자이고 나머지는 쿠폰번호만 있다. 회계팀은 전액 판매촉진비라고 설명한다.

경쟁 가설

경쟁 가설

  • 조사 가설: 과세관청은 상위 거래처를 선별한 부분은 기업업무추진비이고 수령자가 없는 부분은 업무관련성도 입증되지 않는다고 본다.
  • 납세자 가설: 납세자는 구매액이라는 공개 기준을 충족한 불특정 다수 고객에게 지급했고 거래처 포함은 고객구성의 결과일 뿐이라고 본다.

증빙 판단표

법적 요건 주장 사실 확인 자료 지지하는 실제 가설 신뢰도·공백 추가 확인
공개 조건 구매고객 공통 행사 판매촉진계약·행사화면 납세자 가설 게시기간 불명 웹 보관본·승인로그 확보
실제 수령 상위 거래처 비중이 큼 기업업무추진비명세·배부목록 조사 가설 전체 고객분포 없음 거래처별 구매액 비교
지급 실재 상품권 코드가 사용됨 발행사 정산자료 두 가설 공통 최종 사용자 일부 공백 코드별 사용처 조회
대가 없음 지역단체 후원분 혼재 기부금영수증 조사 가설 행사 광고권 여부 불명 후원협약·노출내역 확인
매출 연계 행사 뒤 주문 증가 매출원장·쿠폰 로그 납세자 가설 자연증가 가능성 비행사기간 비교

먼저 판단하기

학습자 잠정 결론

  • 잠정 결론: 지급대상별 재분류가 필요하다.
  • 결정적 사실: 행사조건이 실제로 모든 고객에게 공개되었는지와 코드별 최종 수령자다.
  • 추가로 필요한 증빙: 공고 생성로그, 배부목록, 발행사 정산, 거래처별 구매실적, 후원협약이다.
전문가 피드백 펼치기

전문가 피드백

계획서의 문구보다 실제 배부가 중요하다. 조사팀은 거래처가 포함되었다는 이유만으로 전액 기업업무추진비로 보지 말고 공개조건 충족 여부를 표본 검증해야 하며, 납세자는 수령자 없는 코드를 매출자료로 보완해야 한다.

  • 과세 가능: 임직원·특정 거래처 선별 지급과 무기록 코드가 확인되는 범위
  • 추가 확인 필요: 공개조건은 있으나 코드와 매출 연결이 끊긴 범위
  • 과세 곤란: 모든 코드가 사전 공개조건·구매내역·정산자료와 일치하는 범위

5. 세무사 2차 연결 — 3분

답안 뼈대

  • 쟁점: 세 지출을 기부금·기업업무추진비·판매촉진비로 나누고 한도초과액을 계산하는 것이다.
  • 법리: 대가관계, 수령자의 특정성, 공개된 판매조건을 먼저 판단한 뒤 각 분류의 한도·증빙을 적용한다.
  • 사실포섭: 기부금 10000 중 6000, 특정 거래처 선물 12000 중 8000, 공개 쿠폰 18000 전액이 인정된다.
  • 결론: 손금 인정 32000, 손금불산입 8000이며 조정명세서를 분리한다.

실무 판단을 답안으로

조사요소 답안 기능
수령기관·반대급부 기부금 분류
특정 거래처·적격증빙 기업업무추진비 분류와 한도
공개조건·쿠폰정산 판매촉진비 업무관련성

계산은 6000+8000+18000=32000, 40000-32000=8000이다. IRAC 답안에서는 분류를 마친 뒤에만 숫자를 적용한다.

감점 방지

  • 회계 계정명만으로 세법 분류를 확정하지 않는다.
  • 기업업무추진비 초과액을 판매촉진비로 옮기지 않는다.
  • 문제에서 준 인정액을 현행 한도율처럼 일반화하지 않는다.
  • 최종 수령자와 행사 공개성을 빠뜨리지 않는다.
  • 각 조정명세서의 금액을 소득금액조정합계표와 대사한다.

6. 중요 판례 예측과 해설 — 5분

판례를 먼저 쉽게

이 주제에 카탈로그가 연결한 특정 공식 판례는 없다. 사건번호를 만들지 않고 대가관계·상대방 특정성·공개조건이라는 법률요건과 증빙을 연결한다.

먼저 예측하기

결론 전 예측

행사 문서에는 전 국민 대상이라고 쓰였지만 실제로는 영업부가 선택한 20개 거래처에만 선물을 보냈다면 문서 명칭과 실제 집행 중 어느 사실이 분류를 좌우할지 예측하자.

판례 결론과 이유 펼치기

법원 결론과 이유

  • 주문·결론: 배정된 특정 판결이 없으므로 주문을 창작하지 않는다.
  • 법리: 손금의 성격은 지출 당시의 객관적 목적, 상대방, 대가와 통상성을 종합해 판단한다.
