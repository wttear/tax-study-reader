1. 오늘의 목표와 30초 쉬운 설명 — 2분

쉬운 설명

30초 쉬운 설명

명의가 다르면 곧바로 가공거래도 아니고 곧바로 선의도 아니다. 실제 사업자와 등록번호의 기능을 먼저 찾고, 공급자가 다르면 매입자가 알지 못했고 과실도 없었는지를 별도로 입증한다.

오늘의 목표

오늘 할 수 있어야 하는 것

  • 명의위장 사업자와 선의의 거래상대방의 법정 요소와 경계를 순서대로 설명한다.
  • 명의위장 사업자와 선의의 거래상대방 증거축은 A=계근소 서버원본, B=계좌개설·인출, 미확인=화주·배차지시이다. 이 세 축으로 명의위장 사업자와 선의의 거래상대방 조사측 설명과 납세자측 설명의 강도를 비교한다.
  • 공급가액·세액·귀속 과세기간을 계산해 별지 제21호서식 일반과세자 부가가치세 신고서 · 별지 제39호서식 매입처별 세금계산서합계표의 관련 칸까지 닫는다.

먼저 판단하기

시작 전 판단

거래 실재와 공급자 동일성을 나눈 뒤 실제 단가·수량으로 신고값을 확인하자.

2. 핵심 용어와 법적 판단지도 — 4분

핵심 용어

핵심 용어

개념 현재 수업의 뜻 결정 증빙
명의위장 표시 명의와 실제 사업주체 불일치 운영·자금·등록동기
선의·무과실 불일치 인식 없음과 주의의무 이행 현장·운송·계좌 확인
등록번호 기능 하나의 실제 사업을 특정 신고·사업장·거래연속

판단지도

법적 판단지도

  1. 법 제32조 필요적 기재와 제39조 사실과 다른 세금계산서 불공제를 적용하고 영 제75조 예외, 규칙 제50조 전자기록을 확인한다. 선의·무과실은 매입자가 특별한 사정을 입증한다.
  2. 적용 조문 묶음은 부가가치세법 제32조·제39조 · 부가가치세법 시행령 제75조 · 부가가치세법 시행규칙 제50조이다. 명의위장 사업자와 선의의 거래상대방에서는 계근소 서버원본 사실, ‘실제 공급자 불일치와 위험신호 아래 매입자가 선의·무과실을 입증했는지가 쟁점이다.’ 요건, 별지 제21호서식 일반과세자 부가가치세 신고서 효과의 순서로 읽는다.
  3. 명의위장 사업자와 선의의 거래상대방 수치는 ‘실물수량 10대 × 실제 단가 100,000원 = 확인 공급가액 1,000,000원; 세액 100,000원’으로 검산한다. 계좌개설·인출 금액이 부가가치세 별도인지 포함인지 먼저 확정한다.
  4. 자료 A(현장확인 녹화)의 날짜와 공백항목(촬영 위치·시각)을 대조한다. 귀속표시: 2026년 제2기. 이어서 운송기사 배차앱 거래키를 신고 칸까지 추적한다.

명의위장 사업자와 선의의 거래상대방의 현행 기준은 [시행 2026. 1. 2.] [법률 제21065호, 2025. 10. 1., 타법개정], [시행 2026. 4. 1.] [대통령령 제36133호, 2026. 2. 27., 일부개정], [시행 2026. 4. 1.] [재정경제부령 제9호, 2026. 3. 20., 일부개정]이다. 계근소 서버원본에는 현행 문언을 쓰고, 판례의 구법은 실제 공급자 불일치와 위험신호 아래 매입자가 선의·무과실을 입증했는지가 쟁점이다. 범위에서만 전이한다.

적용 범위와 경계

사업자등록증 한 장 확인만으로 무과실이 되지 않는다. 반대로 명칭 불일치만으로 등록번호가 실제 사업을 특정하지 못한다고 단정하지 않는다.

심화 펼치기

심화

명의위장 사업자와 선의의 거래상대방 심화대조는 작성시각(계근소 서버원본)과 거래키(현장확인 녹화)를 나누는 데서 시작한다. 공백항목=화주·배차지시. 이 항목이 비면 결론을 유보하고, 반증항목=촬영 위치·시각 확인 뒤 명의위장 사업자와 선의의 거래상대방 포섭을 갱신한다.

3. 완성된 쉬운 예제 — 4분

사실

4. 세무조사 증빙 실습 — 8분

결론을 가린 사건

감사 사건 식별자: VAT-AUDIT-112

중립 관찰: 고철 매입자는 신규 거래처 창고를 영상통화로 확인했지만 실제 계근지는 다른 시에 있고 대금계좌는 개설 이틀 뒤 전액 현금인출됐다. 운송기사는 명의대표자를 본 적이 없다고 진술한다.

경쟁 가설

경쟁 가설

  • 조사 가설: 과세관청 가설은 명의대표자가 공급에 관여하지 않았고 위험신호를 무시해 선의·무과실도 없다는 것이다.
  • 납세자 가설: 납세자 가설은 실물·시가·세금계산서·등록을 확인했고 제3자 운송은 업계 관행이라는 것이다.

8분 조사 워크북

  • 원본성(명의위장 사업자와 선의의 거래상대방): 계근소 서버원본 메타데이터를 확인한다. 작성자·생성시각·해시의 대조대상은 화주·배차지시이다.
  • 반증(명의위장 사업자와 선의의 거래상대방): 계좌개설·인출 조사 설명: ‘신규계좌 즉시 현금화’. 납세자 설명: ‘공급자 자금사정’. 두 설명을 분리하고 반박자료(최종 수령자) 확인 뒤 명의위장 사업자와 선의의 거래상대방 강도를 다시 매긴다.
