1. 오늘의 목표와 30초 쉬운 설명 — 2분

쉬운 설명

30초 쉬운 설명

거래가 진짜라는 사실과 세금계산서가 맞다는 사실은 별개다. 공급자·공급받는 자·공급가액·작성연월일 중 필요적 기재가 실제 거래와 어긋나는지, 예외가 있는지 순서대로 본다.

오늘의 목표

오늘 할 수 있어야 하는 것

  • 사실과 다른 세금계산서와 매입세액 불공제의 법정 요소와 경계를 순서대로 설명한다.
  • 사실과 다른 세금계산서와 매입세액 불공제 증거축은 A=계근소 원시파일, B=재고수불부, 미확인=화주코드·운송지시자이다. 이 세 축으로 사실과 다른 세금계산서와 매입세액 불공제 조사측 설명과 납세자측 설명의 강도를 비교한다.
  • 공급가액·세액·귀속 과세기간을 계산해 별지 제21호서식 일반과세자 부가가치세 신고서 · 별지 제39호서식 매입처별 세금계산서합계표의 관련 칸까지 닫는다.

먼저 판단하기

시작 전 판단

실제 공급자와 XML 공급자를 대조하고 제39조 불공제액을 2026년 제1기 매입세액에서 분리하자.

2. 핵심 용어와 법적 판단지도 — 4분

핵심 용어

핵심 용어

개념 현재 수업의 뜻 결정 증빙
필요적 기재사항 등록번호·공급가액·세액·작성연월일 세금계산서 XML
사실과 다름 실제 공급관계와 표시 불일치 물류·계약·금융
공제 예외 영 제75조의 제한된 사유 수정·신고 이력

판단지도

법적 판단지도

  1. 법 제32조의 발급사항, 제38조 공제 구조, 제39조 제1항 제2호 불공제를 함께 적용한다. 영 제69조는 대리·위탁 발급 주체, 제75조는 사실과 다른 기재의 예외를 정하며 규칙 제50조는 전자세금계산서 역할이다.
  2. 적용 조문 묶음은 부가가치세법 제32조·제38조·제39조 · 부가가치세법 시행령 제69조·제75조 · 부가가치세법 시행규칙 제50조이다. 사실과 다른 세금계산서와 매입세액 불공제에서는 계근소 원시파일 사실, ‘실제 도매상과 XML상 유통사가 다른 500,000원 매입세액을 제39조에 따라 공제할 수 있는지가 쟁점이다.’ 요건, 별지 제21호서식 일반과세자 부가가치세 신고서 효과의 순서로 읽는다.
  3. 사실과 다른 세금계산서와 매입세액 불공제 수치는 ‘매입세액 500,000원 - 사실과 다른 세금계산서 불공제 500,000원 = 공제세액 0원’으로 검산한다. 재고수불부 금액이 부가가치세 별도인지 포함인지 먼저 확정한다.
  4. 자료 A(은행 연속이체)의 날짜와 공백항목(마진·손실 부담)을 대조한다. 귀속표시: 2026년 제1기. 이어서 XML 발급로그 거래키를 신고 칸까지 추적한다.

사실과 다른 세금계산서와 매입세액 불공제의 현행 기준은 [시행 2026. 1. 2.] [법률 제21065호, 2025. 10. 1., 타법개정], [시행 2026. 4. 1.] [대통령령 제36133호, 2026. 2. 27., 일부개정], [시행 2026. 4. 1.] [재정경제부령 제9호, 2026. 3. 20., 일부개정]이다. 계근소 원시파일에는 현행 문언을 쓰고, 판례의 구법은 실제 도매상과 XML상 유통사가 다른 500,000원 매입세액을 제39조에 따라 공제할 수 있는지가 쟁점이다. 범위에서만 전이한다.

적용 범위와 경계

거래 실재는 필요조건일 뿐 충분조건이 아니다. 반대로 상호 일부가 달라도 등록번호가 실제 사업을 특정하는 경우에는 2016두62726의 한계를 확인한다.

심화 펼치기

심화

사실과 다른 세금계산서와 매입세액 불공제 심화대조는 작성시각(계근소 원시파일)과 거래키(은행 연속이체)를 나누는 데서 시작한다. 공백항목=화주코드·운송지시자. 이 항목이 비면 결론을 유보하고, 반증항목=마진·손실 부담 확인 뒤 사실과 다른 세금계산서와 매입세액 불공제 포섭을 갱신한다.

사실

VAT 실무 bridge: 원시증빙 → 매출·매입 보조부 → 세금계산서·대체증빙 → 부가가치세 신고서·부속명세서 → 납부·환급

매입자는 전자세금계산서와 거래증빙을 대사해 별지 제39호를 작성하고 예정·확정신고 때 관할 세무서장에게 제출한다. 불공제 500,000원은 별지 제21호 매입세액 공제란에서 제외한다.

중립 관찰: 폐금속 매입 XML은 등록 유통사를 공급자로 적었지만 계근표 차량은 제3 도매상 소유이고 대금은 등록 유통사 입금 직후 전액 이체됐다. 품질검수 서명은 두 회사 직원이 번갈아 사용했다.

8분 조사 워크북

  • 원본성(사실과 다른 세금계산서와 매입세액 불공제): 계근소 원시파일 메타데이터를 확인한다. 작성자·생성시각·해시의 대조대상은 화주코드·운송지시자이다.
  • 반증(사실과 다른 세금계산서와 매입세액 불공제): 재고수불부 조사 설명: ‘등록 유통사 입출고 누락’. 납세자 설명: ‘당일 직송거래’. 두 설명을 분리하고 반박자료(소유권 이전 시각) 확인 뒤 사실과 다른 세금계산서와 매입세액 불공제 강도를 다시 매긴다.

사실과 다른 세금계산서와 매입세액 불공제 회상답의 확신도는 0·1·2로 표시한다. 0 또는 1이면 자료 A=계근소 원시파일; 공백=화주코드·운송지시자. 두 항목을 사실과 다른 세금계산서와 매입세액 불공제 닫힌 해설과 다시 대조한다.

  • 새 사실 전이: 선매입과 손실부담이 추가되면 공급자 불일치가 해소되어 500,000원 공제 가능성을 재계산한다.
