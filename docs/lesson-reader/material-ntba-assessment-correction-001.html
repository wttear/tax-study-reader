1. 오늘의 목표와 30초 쉬운 설명 — 2분

쉬운 설명

30초 쉬운 설명

납세자가 신고한 금액과 세무서가 나중에 고친 금액을 겹쳐 세면 안 된다. 신고, 수정신고, 경정이 각각 얼마를 더했는지 표로 잇는다.

오늘의 목표

오늘 할 수 있어야 하는 것

  • 신고액·수정액·경정액을 전후표로 계산한다.
  • 총계정원장과 세금계산서의 귀속시기 차이를 찾는다.
  • 경정결의서가 확정한 추가 범위를 설명한다.

먼저 판단하기

시작 전 판단

신고 1억 원 뒤 누락 5천만 원을 수정했고 조사팀이 다시 7천만 원을 더하려 한다. 그대로 더해도 될까? 중복 가능성만 표시한다.

2. 핵심 용어와 법적 판단지도 — 4분

핵심 용어

핵심 용어

용어 초보자 뜻 실무상 확인점
신고 납세자가 과세표준과 세액을 계산해 제출하는 행위 최초 신고액을 기준선으로 둔다.
수정신고 적게 신고한 금액을 납세자가 늘려 바로잡는 행위 추가 반영액과 접수일을 확인한다.
경정 과세관청이 신고·결정된 금액을 고치는 처분 이미 반영된 금액을 제외한다.

판단지도

법적 판단지도

판단 단계 결정적 사실 우선 증빙 사실이 뜻하는 결론
최초 기준 신고 과세표준 1억 원 최초 신고서 전후표의 시작값은 1억 원이다.
자진 보정 누락 5천만 원을 수정신고 수정신고서·납부서 경정 전 기준은 1억 5천만 원이다.
추가 차이 귀속시기 차이 2천만 원 총계정원장·세금계산서 중복이 아니면 최종 1억 7천만 원이다.

검토는 위 표의 순서로 진행한다. 서로 다른 날짜·금액·문서를 한 단계로 합치지 않고, 각 문서가 실제로 증명하는 사실까지만 사용한다.

적용 범위와 경계

제22조에 따른 확정 구조에서 신고로 정해진 금액과 경정으로 추가되는 금액을 구별한다. 경정은 이미 반영된 누락액을 다시 더하는 절차가 아니다.

심화 펼치기

심화

개별 세목의 과세요건과 이 단원의 국세기본법 절차를 함께 적용하되, 한 조문의 효과를 다른 조문의 요건으로 대신하지 않는다.

3. 완성된 쉬운 예제 — 4분

사실

비식별 가상 사례다. 비식별 E법인은 2026-03-31 과세표준 1억 원을 신고했다. 2026-05-20 매출 누락 5천만 원을 발견해 수정신고 5천만 원을 더했다. 조사팀은 같은 누락 5천만 원과 별도의 귀속시기 차이 2천만 원을 합친 7천만 원 경정안을 만들었다.

먼저 설명하기

자기설명

최초·수정 후·경정 후 금액을 계산하고, 누락 5천만 원이 두 번 더해지는지 표시한다.

모범 판단 과정 펼치기

전문가 판단 과정

전문가 판단 과정

최초 신고액 1억 원에 수정신고 5천만 원을 더하면 경정 전 과세표준은 1억 5천만 원이다. 조사안의 누락 5천만 원은 이미 반영되어 제외하고 귀속시기 차이 2천만 원만 추가하면 경정 후는 1억 7천만 원이다. 2억 2천만 원으로 계산하면 중복 경정이다.

4. 세무조사 증빙 실습 — 8분

결론을 가린 사건

비식별 F법인의 최초 신고액은 1억 원, 수정신고액은 누락 매출 5천만 원이다. 총계정원장에는 12월 매출 2천만 원이 다음 해로 기록됐고 세금계산서는 12월 29일 발급됐다.

결론을 보지 말고 어느 사실이 법적 경계를 바꾸는지 먼저 적는다.

경쟁 가설

경쟁 가설

  • 조사 가설: 과세관청은 귀속시기 차이 2천만 원만 추가 경정해야 한다고 본다.
  • 납세자 가설: 납세자는 2천만 원도 수정신고 5천만 원 안에 포함됐다고 본다.

증빙 판단표

법적 요건 주장 사실 확인 자료 지지하는 실제 가설 신뢰도·공백 추가 확인
신고 기준액 최초 과세표준이 1억 원이다 법인세신고서 1억 원 기준선 가설 접수본은 금액을 직접 보여 주지만 후속 수정은 반영하지 않는다 수정신고 접수번호와 연결한다
거래 귀속 2천만 원 세금계산서는 12월 거래다 총계정원장·세금계산서 귀속시기 차이 가설 원장 전기일과 세금계산서 발급일이 모순된다 계약·검수일을 추가 대사한다
추가 확정 범위 경정안이 중복 5천만 원을 포함한다 경정결의서 중복 경정 가설 산출표는 계산 구조를 보여 주지만 원거래 동일성 확인이 필요하다 거래처·금액·발급번호를 수정명세와 맞춘다
절차 단계 담당 주체 서류 기한 조사·불복상 확인점
전후표 확정 조사팀과 신고담당 신고·수정·경정 전후표 경정결의 전 같은 거래의 중복 반영 여부를 표시한다

먼저 판단하기

학습자 잠정 결론

가설 하나를 고르고 그 결론을 바꿀 미확인 문서와 이유를 한 문장으로 쓴다.

전문가 피드백 펼치기

전문가 피드백

총계정원장과 세금계산서는 2천만 원의 귀속을, 경정결의서는 추가 확정 범위를 보여 준다. 5천만 원 중복을 빼고 2천만 원만 남는다면 1억 7천만 원이 잠정 결론이다.

5. 세무사 2차 연결 — 3분

답안 뼈대

  • 쟁점: 수정신고 뒤 경정할 추가액
  • 법리: 경정은 기존 확정액의 오류를 바로잡되 이미 수정신고로 반영된 동일 항목을 중복 산입할 수 없다.
  • 사실포섭: 누락 5천만 원은 수정신고에 들어갔고 별도 귀속차이 2천만 원만 남는다.
  • 결론: 경정 후 과세표준은 1억 7천만 원이다.

실무 판단을 답안으로

실무 기록 답안에서의 사용 득점 포인트
증빙 판단표 각 법적 요건 옆에 일치하거나 모순되는 사실을 붙인다. 자료 이름만 나열하지 않고 증명대상을 밝힌다.
잠정결론 미확인 사실이 결론을 바꾸는 방향까지 쓴다. 양쪽 가설을 비교한 포섭이 된다.

감점 방지

날짜, 금액, 권한, 문서의 역할을 생략한 채 추상적 결론만 쓰지 않는다. 적용 법령의 기준일과 사례의 사실확인 한계를 함께 표시한다.

심화 펼치기

심화

답안 끝에는 반대가설이 성립하려면 필요한 한 가지 자료를 적어 결론의 조건을 분명히 한다.

6. 중요 판례 예측과 해설 — 5분

판례를 먼저 쉽게

이 단원은 특정 판결 대신 제22조의 확정 구조를 수치 전후표로 연습한다.

먼저 예측하기

결론 전 예측

경정안 7천만 원 가운데 이미 수정된 거래를 찾는 데 필요한 식별자를 적는다.

판례 결론과 이유 펼치기

법원 결론과 이유

연결된 판결은 없다. 신고 1억 원→수정 후 1억 5천만 원→추가 귀속차이 반영 후 1억 7천만 원으로 계산한다.

구별 사실과 한계

2천만 원의 실제 귀속은 개별 세목의 공급·수익 귀속 규정과 계약 이행일을 추가 확인해야 한다.

후속 상태

기준일 현재 조문과 비식별 수치 사례로 구성했다.

7. 변형사례와 오늘의 회상 — 4분

새 사실에 적용하기

변형사례

2천만 원이 이미 수정신고에 반영됐다는 거래번호가 확인됐다. 추가할 금액이 없어 경정안은 중복 경정으로 보는 방향으로 바뀐다.

오늘의 회상 3문항

  1. 법리 구분: 신고·수정신고·경정 후 과세표준은 각각 얼마인가?
  2. 증빙 선택: 총계정원장·세금계산서·경정결의서는 서로 다른 무엇을 증명하는가?
  3. 새 사실 전이: 2천만 원이 수정신고에 이미 포함되었다면 경정액은 어떻게 달라지는가?

확신도 점검

확신도

세 답에 각각 0 모르겠다 / 1 불확실 / 2 확실을 표시한다. 0과 1은 해당 조문과 증빙 행으로 돌아가 다시 설명한다.

답안 핵심요소 펼치기

답안 핵심요소

  • 법리 구분: 최초 1억 원, 수정 후 1억 5천만 원, 별도 귀속차이까지 인정하면 1억 7천만 원이다.
  • 증빙 선택: 총계정원장은 장부 귀속, 세금계산서는 거래시기 단서, 경정결의서는 추가 확정 범위와 계산을 증명한다.
  • 새 사실 전이: 이미 포함되었다는 새 사실은 추가 차이 요건을 없애므로 추가 경정액 0원이라는 결론으로 바뀐다.
