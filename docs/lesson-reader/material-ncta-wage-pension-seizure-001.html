급여·연금·보험금의 압류 제한

  • 세목 국세징수법
  • 난도 중급
  • 예상 30분

비중: 법과 판례 55% · 조사와 증빙 25% · 세무사 2차 20%

1. 오늘의 목표와 30초 쉬운 설명 — 2분

쉬운 설명

30초 쉬운 설명

급여·연금·보험금은 모두 생활자금과 관련되지만 같은 방식으로 압류하지 않는다. 제41조의 전부 보호 항목인지, 제42조의 일부 제한 채권인지 먼저 분류하고 시행령 제31조·제32조의 금액기준을 사건시점 자료에 적용한다.

오늘의 목표

오늘 할 수 있어야 하는 것

  • 압류금지와 급여 일부압류 제한을 구별한다.
  • 시행령상 250만 원 기준과 고액 급여 계산구조를 적용한다.
  • 인사자료·급여명세서·압류계산서의 산식을 검산한다.

먼저 판단하기

시작 전 판단

급여채권 압류가 왔다면 과세되는 총급여, 소득세, 소득세분 지방소득세 중 어느 값을 먼저 자료에서 찾아야 할까?

2. 핵심 용어와 법적 판단지도 — 4분

핵심 용어

핵심 용어

용어 쉬운 뜻 확인점
압류금지 법이 특정 급부나 재산 전부를 보호하는 경우 제41조 항목과 다른 법률의 전용 제한을 본다.
급여 제한 급여채권 가운데 일정 부분만 보호·압류하는 방식 제42조와 시행령 제32조를 계산한다.
보호금액 생활유지를 위해 남겨야 하는 금액 사건시점 시행령의 금액기준을 쓴다.

판단지도

법적 판단지도

단계 결정적 사실 우선 증빙 판단
급부 성격 임금·퇴직금·연금·보험금 중 무엇인가 인사기록·지급결정서 적용 조문을 분기한다.
총 지급액 과세되는 근로소득에서 어떤 세금을 뺀 기준액인가 급여명세서·원천자료 소득세·소득세분 지방소득세만 뺀 같은 기준으로 산식을 만든다.
법정 보호 제41조 또는 제42조 보호액은 얼마인가 법령 적용표·압류계산서 압류가능액을 계산한다.
실제 지급 사용자·기관이 얼마를 보류·지급했는가 이체내역·제3채무자 회신 과다압류를 확인한다.

적용 범위와 경계

제41조는 압류금지재산, 제42조는 급여채권 등의 제한이다. 제42조 제4항은 과세되는 근로소득에서 소득세와 소득세분 지방소득세를 뺀 금액을 계산기준으로 삼는다. 시행령 제31조는 보험금·예금 등 일부 보호금액, 시행령 제32조는 월 250만 원의 최소 보호와 고액구간 산식을 정한다. 기준일 현재 시행령을 사건시점 급여에 적용하되 다른 법률의 연금 보호도 별도 확인한다.

3. 완성된 쉬운 예제 — 4분

사실

비식별 가상 사례다. O의 과세되는 총급여 560만 원 - 소득세 36만 원 - 소득세분 지방소득세 4만 원 = 기준액 520만 원이다. 기준액의 절반과 최소 보호액을 비교하면 기준액 520만 원 → 절반 260만 원 → 보호액 260만 원 → 압류가능액 260만 원이다. 회사가 320만 원을 송금했다면 실제 송금 320만 원은 60만 원 과다다.

먼저 설명하기

자기설명

과세되는 총급여 560만 원, 소득세 36만 원, 소득세분 지방소득세 4만 원에서 기준액·절반·보호액·압류가능액·실제 송금액을 순서대로 설명한다.

모범 판단 과정 펼치기

전문가 판단 과정

전문가 판단 과정

급여채권은 전액 압류 대상이 아니다. 520만 원에서는 절반 260만 원이 최소 보호액 250만 원보다 크므로 260만 원을 보호하고 260만 원만 압류한다. 고액 예시는 과세되는 총급여 860만 원 - 소득세 54만 원 - 소득세분 지방소득세 6만 원 = 고액 기준액 800만 원이다. 고액 기준액 800만 원 → 절반 400만 원 → 보호액 350만 원 → 압류가능액 450만 원이다. 보호액 350만 원은 시행령 제32조의 300만 원 + (400만 원 - 300만 원) × 1/2로 재현한다.

4. 세무조사 증빙 실습 — 8분

결론을 가린 사건

비식별 P의 회사는 과세되는 총급여 560만 원, 소득세 36만 원, 소득세분 지방소득세 4만 원으로 기준액을 520만 원으로 적고 320만 원을 압류해 송금했다. P는 이 총급여에 포함된 120만 원이 영수증으로 정산한 비과세 실비변상액이므로, 제외하면 과세되는 총급여가 440만 원이라고 주장한다. 두 문서에 적힌 소득세 36만 원과 소득세분 지방소득세 4만 원은 같다.

경쟁 가설

경쟁 가설

  • 징수 가설: 과세관청은 해당 월 총 급여와 상여를 합산해 시행령 계산대로 320만 원을 압류했다고 본다.
  • 납세자 가설: 납세자는 기준액·공제·상여 성격을 잘못 잡아 법정 보호액보다 적게 남겼다고 본다.

증빙 판단표

법적 요건 주장 사실 확인 자료 지지하는 실제 가설 신뢰도·공백 추가 확인
급여 구성 120만 원이 과세되는 근로대가인지 실비변상인지 다툰다 인사자료·상여규정·영수증 합산 또는 제외 가설 지급일은 명확하나 급부 성격이 공백이다 근로계약과 실비정산 결재를 본다
기준액 급여 가설은 과세되는 총급여 560만 원 - 소득세 36만 원 - 소득세분 지방소득세 4만 원 = 기준액 520만 원이다 급여명세서·원천징수자료 급여 합산 가설 피연산자가 모두 있어 산식을 재현할 수 있다 120만 원의 급부 성격을 확인한다
압류액 실제 320만 원을 송금했다 압류계산서·이체내역 과다압류 가설 기준액 520만 원 → 절반 260만 원 → 보호액 260만 원 → 압류가능액 260만 원이면 60만 원 과다다 시행령 제32조를 단계별 재현한다
제외 변형 실비 120만 원 제외 후 과세되는 총급여 440만 원 - 소득세 36만 원 - 소득세분 지방소득세 4만 원 = 기준액 400만 원이다 영수증·실비규정·원천징수자료 더 큰 과다압류 가설 실비변상액 120만 원을 제외한 기준액 400만 원 → 보호액 250만 원 → 압류가능액 150만 원이다 실제 송금 320만 원은 170만 원 과다인지 대사한다
고액 검산 과세되는 총급여 860만 원에서 두 세금 54만 원·6만 원을 빼면 기준액 800만 원이다 급여명세서·원천징수자료·압류계산서 고액구간 산식 가설 기준액 800만 원 → 보호액 350만 원 → 압류가능액 450만 원이다 시행령 제32조 고액산식을 재현한다
절차 단계 담당 주체 서류 기한 조사·불복상 확인점
급부분류→보호액 계산→지급 사용자와 징수담당자 인사자료·급여명세서·압류계산서 매 급여 지급일 사건시점 법령과 실제 송금액을 대사한다

먼저 판단하기

학습자 잠정 결론

120만 원의 급여성, 제42조 제4항 기준액, 시행령 산식을 두 갈래로 재현한 뒤 320만 원 중 초과액을 쓴다.

전문가 피드백 펼치기

전문가 피드백

금액이 크다는 이유만으로 결론내리지 않는다. 총급여 560만 원에서 두 세금 36만 원·4만 원을 빼면 기준액 520만 원, 보호액 260만 원, 압류가능액 260만 원이어서 실제 송금 320만 원은 60만 원 과다다. 실비 120만 원을 제외한 총급여 440만 원에서 같은 두 세금을 빼면 기준액 400만 원, 보호액 250만 원, 압류가능액 150만 원이어서 실제 송금 320만 원은 170만 원 과다다. 고액 검산은 총급여 860만 원에서 두 세금 54만 원·6만 원을 뺀 기준액 800만 원, 보호액 350만 원, 압류가능액 450만 원으로 재현한다.

5. 세무사 2차 연결 — 3분

답안 뼈대

  • 쟁점: 급여·상여에 대한 압류가능액과 보호금액
  • 법리: 제42조 제4항에 따라 과세되는 근로소득에서 소득세·소득세분 지방소득세를 뺀 기준액을 잡고 시행령 제32조의 절반·최소 250만 원·고액구간 산식을 적용한다.
  • 사실포섭: 560-36-4=520 가설은 보호액·압류가능액이 각 260만 원, 실비 제외 후 440-36-4=400 가설은 보호액 250만 원·압류가능액 150만 원인데 실제 320만 원을 송금했다. 고액 860-54-6=800 가설은 보호액 350만 원·압류가능액 450만 원이다.
  • 결론: 어느 분류에서도 과다압류이고, 급여 포함이면 60만 원, 실비 제외면 170만 원을 조정하는 방향이다.

실무 판단을 답안으로

실무 기록 답안 사용 득점 포인트
급부분류표 급여·연금·보험금을 조문별 분기 모두 절반 보호라고 쓰지 않는다.
재계산표 보호액과 실제 압류액을 비교 적용본 금액기준을 명시한다.

감점 방지

250만 원을 모든 연금·보험금에 동일하게 적용하지 않고 제31조와 제32조가 정하는 대상과 다른 법률상 보호를 구별한다.

6. 중요 판례 예측과 해설 — 5분

판례를 먼저 쉽게

연결 판결 없이 현행 법률과 시행령의 보호범위를 실제 급여자료에 적용한다.

먼저 예측하기

결론 전 예측

상여가 근로대가가 아니라 회사 복지규정상 실비변상액이라는 자료가 나오면 급여 합산 결론은 유지될까?

판례 결론과 이유 펼치기

법원 결론과 이유

개별 판결 주문은 없다. 실비변상 성격이 확정되면 급여 산식의 기준액에서 제외될 가능성을 검토하므로 기존 압류계산은 다시 해야 한다.

구별 사실과 한계

연금·보험금은 각 급부의 근거법과 제41조·시행령 제31조 항목을 별도 확인해야 한다.

후속 상태

기준일 현재 제41조·제42조와 시행령 제31조·제32조를 사용했다.

7. 변형사례와 오늘의 회상 — 4분

새 사실에 적용하기

변형사례

상여 120만 원이 영수증으로 정산된 실비변상액이고 급여 산식 대상이 아니라는 규정이 확인되었다. 과세되는 총급여 440만 원 - 소득세 36만 원 - 소득세분 지방소득세 4만 원 = 기준액 400만 원 → 보호액 250만 원 → 압류가능액 150만 원이다. 따라서 실제 송금 320만 원은 170만 원 과다다. 결론은 초과액 60만 원에서 170만 원으로 바뀐다.

오늘의 회상 3문항

  1. 법리 구분: 압류금지재산과 급여 일부압류 제한은 어떻게 다른가?
  2. 증빙 선택: 인사자료·급여명세서·압류계산서는 각각 어떤 값을 증명하는가?
  3. 새 사실 전이: 상여가 실비변상으로 판명되면 압류가능액 결론은 어떻게 변하는가?

확신도 점검

확신도

각 답에 0·1·2를 적고 적용본과 급부 성격을 쓰지 못하면 다시 확인한다.

답안 핵심요소 펼치기

답안 핵심요소

  • 법리 구분: 제41조 전부보호 항목과 제42조 급여 일부제한은 효과가 다르며 시행령 제31조·제32조가 대상별 금액범위를 구체화한다.
  • 증빙 선택: 인사자료는 급부 성격, 급여명세서는 과세 근로소득과 두 법정 세금, 압류계산서는 기준액·절반·보호액·압류가능액, 이체내역은 실제 320만 원 송금을 증명한다.
  • 새 사실 전이: 560-36-4=520 가설은 기준액 520만 원 → 절반 260만 원 → 보호액 260만 원 → 압류가능액 260만 원이고 60만 원 과다다. 실비 제외 후 440-36-4=400 가설은 기준액 400만 원·보호액 250만 원·압류가능액 150만 원으로 실제 송금은 170만 원 과다다. 고액 860-54-6=800 가설은 기준액 800만 원·보호액 350만 원·압류가능액 450만 원이다.
