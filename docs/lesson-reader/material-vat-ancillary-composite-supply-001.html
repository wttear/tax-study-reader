1. 오늘의 목표와 30초 쉬운 설명 — 2분

쉬운 설명

30초 쉬운 설명

부수거래는 계약서에 묶였다는 이유로 자동 결정되지 않는다. 법 제14조는 주된 공급에 통상 포함되는지, 관행상 부수되는지, 독립 목적과 가격이 있는지를 보아 세율과 면세효과를 따라가게 한다.

오늘의 목표

오늘 할 수 있어야 하는 것

  • 주된 거래·부수거래·복합공급의 법정 요소와 경계를 순서대로 설명한다.
  • 주된 거래·부수거래·복합공급 증거축은 A=고객 선택화면, B=가격 승인표, 미확인=옵션 사용률 로그이다. 이 세 축으로 주된 거래·부수거래·복합공급 조사측 설명과 납세자측 설명의 강도를 비교한다.
  • 공급가액·세액·귀속 과세기간을 계산해 별지 제21호서식 일반과세자 부가가치세 신고서의 관련 칸까지 닫는다.

2. 핵심 용어와 법적 판단지도 — 4분

핵심 용어

핵심 용어

개념 현재 수업의 뜻 결정 증빙
주된 공급 고객의 핵심 취득목적 협상·가격구성
부수 재화·용역 통상 포함되거나 관행상 부수 별도선택·해지권
복합공급 독립 목적이 공존 개별가격·원가·효익

판단지도

법적 판단지도

  1. 이 수업의 직접 근거는 법 제14조다. 과세·면세 부수공급 효과는 거래의 통상성·관행·독립성, 별도 선택권과 가격·환불 구조로 판단한다.
  2. 적용 조문 묶음은 부가가치세법 제14조이다. 주된 거래·부수거래·복합공급에서는 고객 선택화면 사실, ‘장비와 교육이 주된 공급에 부수되는 하나의 과세거래인지 독립 복합공급인지가 쟁점이다.’ 요건, 별지 제21호서식 일반과세자 부가가치세 신고서 효과의 순서로 읽는다.
  3. 주된 거래·부수거래·복합공급 수치는 ‘주된 재화 공급가액 9,000,000원 + 통상 부수운송 1,000,000원 = 동일 세율 과세표준 10,000,000원; 세액 1,000,000원’으로 검산한다. 가격 승인표 금액이 부가가치세 별도인지 포함인지 먼저 확정한다.
  4. 자료 A(강사 계약)의 날짜와 공백항목(교육 수료요건)을 대조한다. 귀속표시: 2026년 제1기. 이어서 동종 거래 표본 거래키를 신고 칸까지 추적한다.

주된 거래·부수거래·복합공급의 현행 기준은 [시행 2026. 1. 2.] [법률 제21065호, 2025. 10. 1., 타법개정], [시행 2026. 4. 1.] [대통령령 제36133호, 2026. 2. 27., 일부개정], [시행 2026. 4. 1.] [재정경제부령 제9호, 2026. 3. 20., 일부개정]이다. 고객 선택화면에는 현행 문언을 쓰고, 판례의 구법은 장비와 교육이 주된 공급에 부수되는 하나의 과세거래인지 독립 복합공급인지가 쟁점이다. 범위에서만 전이한다.

적용 범위와 경계

일괄결제·한 장의 계약서는 참고사실일 뿐이다. 고객이 배송·설치·교육을 따로 거절하거나 다른 공급자에게 살 수 있는지, 독립 가격이 있는지 확인한다.

심화 펼치기

심화

주된 거래·부수거래·복합공급 심화대조는 작성시각(고객 선택화면)과 거래키(강사 계약)를 나누는 데서 시작한다. 공백항목=옵션 사용률 로그. 이 항목이 비면 결론을 유보하고, 반증항목=교육 수료요건 확인 뒤 주된 거래·부수거래·복합공급 포섭을 갱신한다.

4. 세무조사 증빙 실습 — 8분

결론을 가린 사건

감사 사건 식별자: VAT-AUDIT-102

중립 관찰: 의료기기 판매자는 면세 교육과 과세 장비를 한 패키지로 팔았다. 견적서는 교육 0원, 내부 원가표는 강사비를 별도 계산하고 고객은 교육 없이 장비만 산 사례도 있다.

경쟁 가설

8분 조사 워크북

  • 원본성(주된 거래·부수거래·복합공급): 고객 선택화면 메타데이터를 확인한다. 작성자·생성시각·해시의 대조대상은 옵션 사용률 로그이다.
  • 반증(주된 거래·부수거래·복합공급): 가격 승인표 조사 설명: ‘교육 0원 표시’. 납세자 설명: ‘장비가에 내재’. 두 설명을 분리하고 반박자료(독립 할인·환불) 확인 뒤 주된 거래·부수거래·복합공급 강도를 다시 매긴다.
  • 금액·시기(주된 거래·부수거래·복합공급): 강사 계약 거래키로 주된 재화 공급가액 9,000,000원 + 통상 부수운송 1,000,000원 = 동일 세율 과세표준 10,000,000원; 세액 1,000,000원을 재계산한다. 귀속=2026년 제1기; 남은 공백=교육 수료요건.
  • 신고 연결(주된 거래·부수거래·복합공급): 동종 거래 표본 사실을 별지 제21호서식 일반과세자 부가가치세 신고서의 해당 칸에 옮긴다. 동일 모델 비교 미확인분은 주된 거래·부수거래·복합공급 금액에서 보류한다.
  • 최종포섭(주된 거래·부수거래·복합공급): 고객 선택화면·가격 승인표·강사 계약의 거래번호·작성시각을 맞춘다. 귀속=2026년 제1기. 쟁점=장비와 교육이 주된 공급에 부수되는 하나의 과세거래인지 독립 복합공급인지가 쟁점이다. 반대사실 후보=동일 모델 비교.

주된 거래·부수거래·복합공급 잠정판정 접점은 작성시각=고객 선택화면, 거래키=가격 승인표, 금액원본=강사 계약이다. 확인항목=동일 모델 비교. 이 항목이 없으면 주된 거래·부수거래·복합공급 정상·부정 결론을 모두 유보한다.

  • Rule: 이 수업의 직접 근거는 법 제14조다. 과세·면세 부수공급 효과는 거래의 통상성·관행·독립성, 별도 선택권과 가격·환불 구조로 판단한다.
  • Application: 옵션 사용률 로그, 교육 환불규정, 동일모델 장비 단독계약이라는 독립 증거 3종으로 독립성을 포섭한다. 예제 운송은 통상 부수이므로 10,000,000원·1,000,000원을 제1기 별지 제21호에 합산한다. 독립 증거 3종: 고객 선택화면·가격 승인표·강사 계약. 귀속 과세기간: 2026년 제1기. 신고 위치: 별지 제21호서식 일반과세자 부가가치세 신고서.
  • Conclusion: 예제 운송은 장비 인도에 통상 포함되어 동일 세율로 합산하지만, 감사사건 교육은 독립 선택·환불이 확인될 때 별도 공급으로 나눈다.

실무 판단을 답안으로

주된 거래·부수거래·복합공급 검산식은 주된 재화 공급가액 9,000,000원 + 통상 부수운송 1,000,000원 = 동일 세율 과세표준 10,000,000원; 세액 1,000,000원이다. 단위 원본=고객 선택화면; 귀속 원본=강사 계약. 두 원본을 별지 제21호서식 일반과세자 부가가치세 신고서에 연결하여 주된 거래·부수거래·복합공급 신고 칸까지 추적한다.

감점 방지

  • 고객 선택화면 작성주체를 확인하고, 주된 거래·부수거래·복합공급 현행조문은 사건 당시 조문과 구분한다.
  • 가격 승인표 위험신호만으로 주된 거래·부수거래·복합공급 부인을 확정하지 않는다. 반증=독립 할인·환불; 독립자료=강사 계약.
  • 주된 거래·부수거래·복합공급 계산 귀속=2026년 제1기; 신고 위치=별지 제21호서식 일반과세자 부가가치세 신고서의 구체 칸.

먼저 예측하기

결론 전 예측

현행 조문의 각 요건과 증거 공백을 먼저 적고, 법원의 결론을 빌리지 않은 잠정 답안을 만든다.

판례 결론과 이유 펼치기

법원 결론과 이유

직접 연결한 중요판례가 없는 쟁점이다. 따라서 가상사례를 판결처럼 인용하지 않고 법률·시행령·시행규칙의 역할과 사실 포섭만으로 결론을 닫는다.

구별 사실과 한계

다른 세목이나 인접 VAT 판례를 결론 근거로 옮기지 않는다. 실제 사건이 발견되면 주문·사건기간·구별 사실과 현행법 전이 범위를 공식 원문에서 새로 확인한다.

후속 상태

주된 거래·부수거래·복합공급 연결판례의 주문·사건기간·후속상태는 공식 판례정보로 확인했다. 고객 선택화면 검증표에는 파기환송 뒤 결과가 확인되지 않은 사건을 확정승소로 적지 않는다.

변형사례
