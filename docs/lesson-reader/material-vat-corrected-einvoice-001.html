1. 오늘의 목표와 30초 쉬운 설명 — 2분

쉬운 설명

30초 쉬운 설명

수정세금계산서는 틀린 숫자를 편의상 덮어쓰는 문서가 아니다. 환입·계약해제·착오 등 영 제70조 사유와 작성일, 당초 전자문서 연결키에 맞춰 증감분을 해당 과세기간에 반영한다.

오늘의 목표

오늘 할 수 있어야 하는 것

  • 수정세금계산서와 전자세금계산서의 법정 요소와 경계를 순서대로 설명한다.
  • 수정세금계산서와 전자세금계산서 증거축은 A=택배 인수스캔, B=품질검수 원본, 미확인=반품 거절권이다. 이 세 축으로 수정세금계산서와 전자세금계산서 조사측 설명과 납세자측 설명의 강도를 비교한다.
  • 공급가액·세액·귀속 과세기간을 계산해 별지 제21호서식 일반과세자 부가가치세 신고서 · 별지 제38호서식 매출처별 세금계산서합계표 · 별지 제39호서식 매입처별 세금계산서합계표의 관련 칸까지 닫는다.

먼저 판단하기

시작 전 판단

당초 잔액, 감소 공급가액, 감소세액, 환입 발생 과세기간을 네 칸으로 먼저 적자.

2. 핵심 용어와 법적 판단지도 — 4분

핵심 용어

핵심 용어

개념 현재 수업의 뜻 결정 증빙
환입 반품으로 공급가액 감소 반품검수·회수운송
수정 발급 영 제70조 사유별 작성방법 당초 승인번호·수정코드
전자 전송 영 제68조·규칙 제50조 방식 인증시각·국세청 응답

판단지도

법적 판단지도

  1. 법 제32조, 영 제70조의 수정사유·작성연월일을 적용하고 영 제68조와 규칙 제50조로 전자발급 기록을 검증한다. 환입은 실제 반환이 발생한 때 감소 세금계산서를 발급한다.
  2. 적용 조문 묶음은 부가가치세법 제32조 · 부가가치세법 시행령 제68조·제70조 · 부가가치세법 시행규칙 제50조이다. 수정세금계산서와 전자세금계산서에서는 택배 인수스캔 사실, ‘환입 200,000원의 수정사유·작성일·당초 전자문서 연결이 영 제70조에 맞는지가 쟁점이다.’ 요건, 별지 제21호서식 일반과세자 부가가치세 신고서 효과의 순서로 읽는다.
  3. 수정세금계산서와 전자세금계산서 수치는 ‘당초 공급가액 1,000,000원 - 환입 200,000원 = 수정후 공급가액 800,000원; 감소 세액 200,000원 × 10% = 20,000원’으로 검산한다. 품질검수 원본 금액이 부가가치세 별도인지 포함인지 먼저 확정한다.
  4. 자료 A(당초 XML 승인번호)의 날짜와 공백항목(국세청 연결응답)을 대조한다. 귀속표시: 2026년 제2기. 이어서 고객 재고원장 거래키를 신고 칸까지 추적한다.

수정세금계산서와 전자세금계산서의 현행 기준은 [시행 2026. 1. 2.] [법률 제21065호, 2025. 10. 1., 타법개정], [시행 2026. 4. 1.] [대통령령 제36133호, 2026. 2. 27., 일부개정], [시행 2026. 4. 1.] [재정경제부령 제9호, 2026. 3. 20., 일부개정]이다. 택배 인수스캔에는 현행 문언을 쓰고, 판례의 구법은 환입 200,000원의 수정사유·작성일·당초 전자문서 연결이 영 제70조에 맞는지가 쟁점이다. 범위에서만 전이한다.

적용 범위와 경계

당초 공급가액 1,000,000원을 800,000원으로 재작성하는 것과 환입 200,000원의 음수 수정분을 발급하는 것을 구분한다. 세액 감소는 20,000원이고 귀속기간을 빠뜨리지 않는다.

심화 펼치기

심화

수정세금계산서와 전자세금계산서 심화대조는 작성시각(택배 인수스캔)과 거래키(당초 XML 승인번호)를 나누는 데서 시작한다. 공백항목=반품 거절권. 이 항목이 비면 결론을 유보하고, 반증항목=국세청 연결응답 확인 뒤 수정세금계산서와 전자세금계산서 포섭을 갱신한다.
